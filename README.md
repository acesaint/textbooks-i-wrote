## 🏠 关于这个仓库

这是我（和我的朋友们）写教材的地方。

每本教材都遵循同一个原则：**把读者当成从没接触过这个领域的小白**，用最浅显的语言、最生活的比喻，把知识讲到「每天花 1 小时就能学会」的程度。

这里不追求快，追求**学得会、记得住、用得上**。

## 🐍 第一本教材讲了什么

《Python 零基础入门教材》（大魔王博士）是一套 **21 天课程**，每天 1 小时，从「电脑为什么能听懂我们说话」讲起，一路到能自己写出实用小程序。

- **Day 1–2**：编程是什么 + 装好环境，写出人生第一行代码
- **Day 3–7**：认识数据（变量、数字、文字、列表、字典）
- **Day 8–12**：条件判断 + 循环，并做出第一个小游戏「猜数字」
- **Day 13–15**：函数、模块化思维，学会自己修 bug
- **Day 16–19**：文件读写、异常处理，做出「批量文件整理」实用工具
- **Day 20–21**：面向对象入门 + 总复习，并给出三条进阶路线（数据分析 / 办公自动化 / 做网站）

附录另附：常见报错速查表、巩固练习清单、21 天打卡表。

## 🧙 第二本教材讲了什么

《大语言模型原理》（大魔王博士，重写版）**写给智商 100 的普通人**：不要求数学和编程基础，用大白话和生活比喻，把大语言模型从黑盒子拆开。全书 13 章、每章约 30 分钟可读完（总计约 2.5 小时），目标是让你**以后用大模型时更清醒、更顺手**。每章固定五件套：本章目标 → 正文 → 记住三句话 → 动手试一试 → 快问快答。

四关递进：

- **第一关 · 看穿它是什么（第1～2章）**：一台"超级接龙"机器；Token 与词向量
- **第二关 · 打开引擎盖（第3～6章）**：注意力（查字典比喻）→ Transformer → 预训练 → SFT/RLHF 对齐
- **第三关 · 看它怎么干活（第7～9章）**：推理全过程（Prefill/Decode、KV Cache、温度）→ 上下文窗口 → 幻觉的机制与对策
- **第四关 · 把它用好（第10～13章）**：提示词 → RAG 与微调 → Agent 与工具调用 → 安全、成本与选型

附录另附：术语速查表、20 题总复习、一页纸总结（可打印贴在显示器旁）。

## 🚀 第三本教材讲了什么

《编程入门》（大魔王博士）**不教任何一门语言的语法**，而是回答那个最容易被跳过、也最要命的问题：**在你还不会写代码的时候，先搞清楚「写代码」这件事到底在干什么。**

全书 **8 关 53 章**，约 27 万字，每章 20–30 分钟可读完，每章固定五件套：本章目标 → 正文（生活比喻讲透）→ 极简伪代码 → 本章重点回顾 → 想一想。

- **第一关 · 编程的本质（第 2–8 章）**：它到底是什么？——一份精确到变态的菜谱、CPU 怎么「思考」、内存与硬盘、0 和 1、从想法到程序、算法的灵魂
- **第二关 · 历史脉络（第 9–15 章）**：它从哪来？——织布机与第一位程序员、ENIAC 与冯·诺依曼、汇编、高级语言革命、C 与 Unix、Java/JS/Python、开源与 AI
- **第三关 · 编程思维（第 16–22 章）**：程序员怎么想？——计算思维、分解、抽象、模式识别、算法思维、调试思维、工程思维
- **第四关 · 语言动物园（第 23–32 章）**：用什么？——编译/解释、静态/动态、Python/JS/Java/C#/C++/Rust/Go/Swift/Kotlin、SQL 与 HTML、语言对比总表
- **第五关 · 工具箱（第 33–36 章）**：编辑器和 IDE、命令行、Git 与 GitHub、包管理与 AI 助手
- **第六关 · 上手实践（第 37–46 章）**：装环境、变量、类型、运算、判断、循环、函数、列表字典、文件读写，最后做出一个**完整的命令行待办清单工具**
- **第七关 · 面向对象与质量（第 47–49 章）**：类与对象、异常处理、好代码的六个特征
- **第八关 · 路线与未来（第 50–53 章）**：API 与第三方库、**如何选择第一门语言**、**推荐学习路径**（数据AI / Web / 效率工具三条路线图）、避坑十三条军规

附录另附：全书核心概念速查表、常见问题 30 问、**你的第一个项目清单（15 个项目按难度排序）**。

> 💡 **读法建议**：如果你打算学任何一门语言，先读这本书，能让你后面少走一半弯路。读完第 51–52 章，你会明确知道自己该选什么、怎么走。

## 🎯 第四～六本：《讲不明白，是你没懂》三书

一套讲「怎么才算真的学会」的小书，**一本只讲一把刀**。三本各自独立、都能单独读；合起来是一套完整的「把知识想清楚、讲明白」的工具箱。

- **每本 7 章，每章 7000–11000 字**（20–30 分钟读完，按 350–450 字/分钟算）
- **章内固定七段**：生活痛点故事 → 大白话讲概念 → 可执行步骤（流程图）→ 思维导图 → 立刻能做的练习 → 常见误区与避坑 → 费曼式小结（200 字内复述）
- **写给智商 100 的普通人**：不要求任何专业背景，每个抽象概念后面立刻跟一个生活例子
- **每章末尾都有"现在就能做"的练习**，标了耗时，最短的只要 3 分钟

### 第四本 ·《费曼学习法》：把知识讲成人话

> 一句话：**你以为你懂了，其实你只是"眼熟"。**

- 第1章 你以为你懂了，其实只是"眼熟"
- 第2章 费曼学习法到底在干什么：给知识"翻译"一遍
- 第3章 第一步：挑一个概念，讲给一个十二岁的小孩
- 第4章 卡壳的地方，就是你的知识漏洞
- 第5章 扒掉术语，只留骨架：简化与类比的手艺
- 第6章 为什么你讲了十遍还是没懂：六个坑
- 第7章 进阶：把费曼法变成每天十五分钟的习惯

适合：读了很多书却讲不出来、听完课觉得懂了考试就懵、开会汇报总被问住的人。

### 第五本 ·《第一性原理》：拆到地基再重搭

> 一句话：**别人都在照着做，不代表那条路是对的。**

- 第1章 别人都在"照着做"，凭什么你要"从头想"
- 第2章 第一性原理：拆到不能再拆的那一层
- 第3章 你脑子里有多少想法，是别人塞给你的
- 第4章 拆解五问：把一个大问题拆到地基
- 第5章 从地基重新搭：组合式创新怎么落地
- 第6章 第一性原理不是抬杠，也不是重新发明轮子
- 第7章 进阶：给自己建一个"原理库"

适合：厌倦了"行业惯例就是这样"、想做出点不一样的东西、又不想变成杠精的人。

### 第六本 ·《奥卡姆剃刀》：砍掉多余的那一刀

> 一句话：**你不是想太少，是想太多。**

- 第1章 你不是想太少，是想太多
- 第2章 奥卡姆剃刀：如无必要，勿增实体
- 第3章 三个刀口：砍假设、砍步骤、砍解释
- 第4章 怎么判断"哪个更简单"：可检验的才算数
- 第5章 剃刀的反面：什么时候"简单"是错的
- 第6章 把剃刀用成偷懒许可证，是最大的坑
- 第7章 进阶：三把刀合起来用

适合：方案越改越复杂、解释越写越长、选择越列越多，最后什么都没做成的人。

> 🧭 **三本怎么配合读**：先用**费曼法**把一件事讲出来，讲到卡壳的地方；再用**第一性原理**把卡住的那个点拆到地基，看它到底建立在什么之上；最后用**奥卡姆剃刀**把拆出来的东西重新拼回去，砍掉所有不必要的假设和步骤。第六本第 7 章给了这套组合拳的完整流程。
