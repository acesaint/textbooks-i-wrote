## 📅 Day 1 · 编程是什么？Python 的故事

> 🎯 **今日目标**：搞懂"编程到底在干嘛"，知道 Python 是什么、能做什么、为什么适合新手。
> 今天不写代码，纯涨见识 + 建立正确心态，轻轻松松。

### 一、编程，到底是在干什么？

先记住这句话，它是全书的地基：

> **编程，就是把你想让电脑做的事，一步一步、用电脑能听懂的话写下来。**

电脑这个东西，其实"笨"得可爱。它不会举一反三，不会自己发挥，你说一句它做一句。
但它有三个巨大优点：**快**（一秒钟算几百万次）、**稳**（不累不烦不出错）、**记性好**（存多少东西都忘不了）。

我们写代码，就是在利用这三个优点，让电脑替我们干活。

#### 一个比喻：写给机器人的菜谱

想象你有一个机器人保姆，力大无穷、手脚麻利，但**完全不通人情世故**。你让它"做碗番茄炒蛋"，它站着不动——因为它不知道"做"具体是哪几个动作。

你必须写成这样，它才会动：

```
1. 从冰箱拿出 2 个番茄和 3 个鸡蛋
2. 把番茄洗干净，切成块
3. 把鸡蛋打到碗里，搅匀
4. 开火，倒油，等油热
5. 倒鸡蛋，炒熟后盛出
6. 倒番茄，炒出汁
7. 把鸡蛋倒回去，一起炒
8. 关火，装盘
```

**这份步骤清单，就是"程序"。** 编程，就是写这份清单。
而 Python、C、Java 这些，是写这份清单可以选用的"语言"——就像你用中文、英文、日文写菜谱都行，关键是机器人（电脑）能听懂。

> 💡 **核心认知**
> 学编程，一半是学"怎么把事说清楚"（把大问题拆成小步骤），一半是学"某门语言的具体说法"。
> 前者是内功，越练越通用；后者是招式，换门语言再学一遍就行。**这本书主要教你内功，顺带教会 Python 这门招式。**

### 二、Python 是一门什么样的语言？

- **名字由来**：作者 Guido（吉多）是英剧《Monty Python's Flying Circus》（蒙提·派森的飞行马戏团）的粉丝，于是给这门语言起名 Python（和蟒蛇本无关系，虽然 logo 是两条蛇 🐍）。
- **出生年份**：1989 年，到现在三十多岁了，是一门成熟、稳定、全世界都在用的语言。
- **设计哲学**：**"优雅、明确、简单"**。Python 的设计者坚信：写代码应该像写英文一样易读。所以它有很多"人性化"的规定，让新手不容易被劝退。

> 🎬 **Python 的历史小故事（了解即可）**
> 1989 年圣诞节，荷兰程序员 Guido 闲着没事，想给自己找点事做，决定设计一门"更好用、更好读"的新语言。
> 他大概没想到，这个"圣诞副业"后来成了全球最流行的编程语言之一，被 Google、NASA、Netflix、抖音……无数公司用来干正事。
> **启示**改变世界的大项目，有时就始于一个"想做点有用东西"的念头。你现在学 Python，也是在给自己的未来埋一颗种子。

### 三、Python 能干什么？（为什么值得学）

Python 最大的特点是"**全能**"和"**入门容易**"。学会基础后，你可以往很多方向发展：

| 方向 | 能做的事 | 生活化的例子 |
|------|----------|--------------|
| 🧮 **数据分析** | 处理 Excel、做统计、画图表 | 几万行销售数据，几秒算出哪个产品最赚钱 |
| 🤖 **办公自动化** | 批量处理文件、自动收发邮件、定时任务 | 一键把 1000 张照片按日期归类命名 |
| 🕸️ **网络爬虫** | 自动抓取网页信息 | 每天自动抓取你关注的商品价格，降价了提醒你 |
| 🌐 **做网站** | 搭建自己的网页、小程序后端 | 给朋友做个投票网站、个人博客 |
| 🤖 **人工智能** | 训练模型、做 AI 应用 | 做一个能识别猫狗图片的小程序（AI 时代的入场券） |

> ✅ **一句话总结**
> 无论你以后想靠 Python 找工作、做副业，还是纯粹当个"提效工具"，
> 它都是性价比最高的入门语言——**上手最快、用处最广、社区最大（遇到问题一搜一大把答案）。**

### 四、今天你需要建立的三个"程序员思维"

比语法更重要的，是下面这三个看问题的角度，从今天就开始有意识地练：

1. **把大问题拆成小步骤。** "做一顿饭"太笼统，拆成"买菜→洗菜→切菜→炒菜→装盘"才能执行。编程就是训练这种"拆解"能力。
2. **精确，再精确。** 人对模糊有容忍度（你说"倒点油"他懂），电脑没有（"一点"是多少克？）。写代码会逼你把话说得清清楚楚。
3. **先让程序跑起来，再慢慢完善。** 新手总想"一次写完美"，结果迟迟不敢下手。高手的做法是：先写个能跑的最简版本，再一点点加功能。

3. **定个计划**：在手机里设一个每天固定的"Python 1 小时"闹钟（比如晚上 9 点）。**固定时间做固定的事，是坚持下来最大的秘诀。**

### 📌 今日小结

- **编程 = 给电脑写一份"步骤说明书"**，它照做。
- 电脑很笨但极快、极稳、记性极好，我们借它的长处干活。
- **Python**：1989 年 Guido 创造的、以"简单易读"为哲学的全能语言，最适合新手入门。
- 三个程序员思维：**拆解问题、追求精确、先跑起来再完善**。

## 📅 Day 2 · 搭好"练功房"，写出第一行代码

> 🎯 **今日目标**：把能运行 Python 的地方准备好，然后亲眼看着电脑执行你的第一条命令。
> 今天你会真正"碰"到代码，记住那种"我让电脑动起来了"的爽感。

### 一、先认识你的第一个"咒语"：print

在 Python 里，让电脑在屏幕上显示一段文字，用的是 `print`（意思就是"打印"）。用法极其简单：

```python
print("你好，世界")
```

把上面这行敲进去运行，屏幕上就会出现：`你好，世界`。

我们来解剖一下这行"咒语"的每一部分：

| 部分 | 它是什么 | 作用 |
|------|----------|------|
| `print` | 一个**命令**（英文"打印"） | 告诉电脑"我要显示点东西" |
| `( )` | 一对**括号** | 把要显示的内容"装"进去送给 print |
| `"你好，世界"` | 一段**文字** | 真正要显示的内容 |
| `""` 引号 | 文字的"包装" | 告诉电脑：这是文字，不是命令 |

> 💡 **为什么文字要用引号包起来？**
> 因为电脑需要区分"这是给人看的文字"和"这是给电脑执行的命令"。
> 引号就像给文字穿上外套：`你好` 是文字，而 `print` 没穿外套，电脑就当它是命令来执行。
> **规则记牢：你想显示的文字，必须用英文引号 `""` 或 `''` 包起来。**

> ⚠️ **新手必踩的坑（先避开）**
> 1. 引号要用**英文**的 `"`，不要用中文的 `“”`。中英文标点混用是新手第一大报错来源！
> 2. 括号要**成对**，`(` 就要有 `)`。
> 3. 一行代码写完整再运行，别写一半。

你需要一个地方来敲代码、看结果。有两种选择，**强烈建议新手先用方案 A**，零门槛；以后想深入再用方案 B。

### 三、你的第一个完整程序

现在，我们写一个稍微像样点的程序，体会一下"程序是一步一步执行的"：

```python
print("=== 我的第一个程序 ===")
print("你好，我是你的电脑。")
print("从现在起，我听你的指挥。")
print("========================")
```

运行后你会看到四行文字，从上到下依次出现。注意：**电脑是严格从上往下、一行一行执行的**，不会跳，也不会乱。这是所有程序的基本节奏。

### 四、再进一步：让电脑"说"出会变的话

`print` 不仅能显示固定文字，还能把"算出来的结果"显示出来。比如：

```python
print("我想学 Python")
print(1 + 1)
```

第一行显示：`我想学 Python`
第二行显示：`2` —— 电脑真的帮你算了 1+1！

> 💡 看出来了吗？**有引号的是"原样显示的文字"，没引号的是"让电脑去算的东西"。**
> 这个区别非常重要，后面天天要用。现在先有个印象即可。

### ✏️ 今日练习（约 20 分钟）

1. **跑通第一行**：在你的练功房里（在线或本地都行）运行 `print("你好，世界")`，亲眼看到结果。
2. **改一改**：把文字换成你自己的话，比如 `print("我开始学 Python 啦")`，再运行一次。
3. **写个四行小程序**：照着上面"第一个完整程序"，改成介绍你自己的四行字，运行看看。
4. **故意犯个错**：把引号去掉一个，写成 `print("你好)`，运行一下，看看电脑给你什么"脸色"（报错）。**记住这个报错长什么样，明天开始你会经常和它打交道。**

### 📌 今日小结

- `print(要显示的内容)` 是让电脑"说话"的命令。
- **文字必须用英文引号 `""` 包起来**；没引号的内容电脑会当成命令或计算去处理。
- 程序**从上到下、一行一行**执行，不会乱。
- 练功房两种搭法：**在线编辑器**（先用这个）或 **本地装 Python + VS Code**（长期用）。

## 📅 Day 3 · 变量：给信息"贴标签"

> 🎯 **今日目标**：理解"变量"这个编程里最核心的概念。它是后面一切的地基，务必吃透。

### 一、变量是什么？一个"贴标签的盒子"

先说结论：

> **变量，就是一个贴了名字的盒子，用来装数据。你需要用的时候，喊盒子的名字，就能把里面的东西取出来。**

生活里到处都是"变量"思维。你手机通讯录里存着"妈妈的电话"——"妈妈的电话"这个名字（标签），对应一串号码（盒子里的东西）。名字不变，号码可以换（妈妈换号了你就改一下），但你永远通过"妈妈的电话"这个名字找到她。

在编程里，我们这样创建一个变量：

```python
name = "小明"
```

这行代码的意思是：**造一个贴了 `name` 标签的盒子，往里放进文字"小明"。**

解剖一下：

| 部分 | 作用 |
|------|------|
| `name` | 盒子的**名字**（你自己起，规则见下） |
| `=` | **赋值符号**，意思是"把右边的放进左边的盒子" |
| `"小明"` | 真正装进盒子的**内容** |

> 💡 **`=` 在编程里不是"等于"，而是"赋值"！**
> 数学里 `a = b` 表示"a 和 b 相等"；编程里 `age = 18` 表示"把 18 这个值，装进叫 age 的盒子"。
> 它是**从右往左**动作：先算右边的，再装进左边。这个观念转过来，变量就懂一半了。

### 二、把盒子里的东西拿出来用

创建了变量，怎么用？直接**喊它的名字**就行：

```python
name = "小明"
print(name)          # 显示：小明
print("我叫" + name)  # 显示：我叫小明
```

> 💡 `"我叫" + name` 里的 `+`，在文字世界里是"拼接"：把两段文字粘成一段。
> 就像胶水，把"我叫"和"小明"粘成"我叫小明"。（数字世界里 `+` 是相加，明天细说。）

### 三、给盒子起名字的规矩

变量名不能乱起，有几条简单规则（记住就不会踩坑）：

| 规则 | 说明 | 例子 |
|------|------|------|
| ✅ 只能用字母、数字、下划线 | 不能有空格、中文、特殊符号 | `my_name` ✅ / `my name` ❌ |
| ✅ 不能用数字开头 | 开头得是字母或下划线 | `age1` ✅ / `1age` ❌ |
| ✅ 区分大小写 | `Age` 和 `age` 是两个盒子 | 小心拼写 |
| ⚠️ 避开"保留字" | 有些词 Python 自己占了（如 `if`、`for`、`print`） | 别拿它们当名字 |
| 💡 建议用小写 + 下划线 | 这是行业惯例，清晰好读 | `user_name`、`total_price` |

> 💡 **起名的最高境界是"见名知意"。** `a = 18` 鬼知道是什么；`age = 18` 一看就懂。
> 好程序员都把起名当成头等大事，因为代码是写给人看的，顺便给电脑运行。

### 四、盒子里能装什么？—— 数据类型初识

盒子（变量）里能装不同"种类"的东西。Python 里最基础的三种，今天先认识：

| 类型 | 英文名 | 装什么 | 例子 | 特征 |
|------|--------|--------|------|------|
| 🔢 整数 | `int` | 不带小数点的数 | `18`、`2026`、`-5` | 能算加减乘除 |
| 📝 字符串 | `str` | 文字/文本 | `"小明"`、`"你好"` | **必须用引号包住** |
| 🔀 布尔 | `bool` | 只有"真/假"两种 | `True`、`False` | 表示"是/否" |

> 💡 **字符串（str）**：英文 string，就是"一串字符"。只要你想表示文字，就用引号包起来，它就成了字符串。
> **布尔（bool）**：只有两个值——`True`（真）和 `False`（假），后面做"判断"时极其重要。
> （还有一种"小数"叫 `float`，明天和数字一起细说。）

你可以用 `type()` 这个命令，问电脑"这个盒子里装的是哪种类型"：

```python
age = 18
name = "小明"
is_student = True

print(type(age))         # <class 'int'>
print(type(name))        # <class 'str'>
print(type(is_student))  # <class 'bool'>
```

（看不懂 `print` 里那串英文没关系，知道它在告诉你"类型"就行。）

### 五、变量最大的好处：随时能改

变量之所以叫"变"量，就是因为它里面的值**可以改变**：

```python
age = 18
print(age)   # 显示 18

age = 19
print(age)   # 显示 19——过了一年，长了一岁
```

同一个盒子 `age`，先装 18，后装 19。**名字没变，内容换了。** 这就是现实世界的写照：你还是你，但你的年龄在变。

### ✏️ 今日练习（约 20 分钟）

1. **建三个盒子**：创建变量 `my_name`（你的名字）、`my_age`（你的年龄）、`like_python`（是否喜欢 Python，用 True/False），然后用 `print` 把它们分别显示出来。
2. **拼接一句话**：用 `print("我叫" + my_name + "，今年" + ...)` 这样的方式，把自己介绍出来（提示：年龄是数字，要拼进句子里，需要先用 `str()` 包一下，写成 `str(my_age)`。先照着做，不懂没关系）。
3. **改一改**：把 `my_age` 改成比你实际年龄大 1 的数，再打印，体会"变量会变"。
4. **辨类型**：用 `type()` 分别看看 `my_name`、`my_age`、`like_python` 各是什么类型。

### 📌 今日小结

- **变量 = 贴了名字的盒子**，用来装数据，靠名字取用。
- `=` 是**赋值**（把右边装进左边），不是"等于"。
- 变量名规矩：字母数字下划线、数字不开头、区分大小写、见名知意。
- 三种基础类型：**整数 int、字符串 str（带引号）、布尔 bool（True/False）**。
- 变量之"变"：同一个名字，内容可以随时换。

## 📅 Day 4 · 数字与运算：让电脑当计算器

> 🎯 **今日目标**：学会用 Python 做数学计算，认识"小数"，并搞定"数字和文字互相转换"这个小关卡。

### 一、两种数字：整数和小数

昨天认识了整数（`int`），今天补上它的兄弟：

| 类型 | 英文名 | 长什么样 | 例子 |
|------|--------|----------|------|
| 🔢 整数 | `int` | 不带小数点 | `18`、`100`、`-7` |
| 🔀 小数 | `float` | 带小数点 | `3.14`、`19.9`、`-0.5` |

> 💡 为什么小数叫 `float`（浮点）？因为小数点在数里会"浮动"：`3.14` 和 `0.314` 小数点位置不同。
> 这个词不用死记，知道"小数在 Python 里叫 float"就行。

### 二、电脑比你算得快：基本运算

Python 支持所有你熟悉的数学运算，写法基本一样：

```python
print(10 + 3)    # 加法 → 13
print(10 - 3)    # 减法 → 7
print(10 * 3)    # 乘法 → 30（注意是星号 *，不是叉）
print(10 / 3)    # 除法 → 3.3333...（除法结果一定是小数！）
```

有几个运算符号，可能和学校里学的不一样，特别记一下：

| 运算 | 符号 | 例子 | 结果 | 说明 |
|------|------|------|------|------|
| 乘法 | `*` | `10 * 3` | 30 | 星号，别写成 `x` |
| 除法 | `/` | `10 / 2` | 5.0 | **结果必是小数**，`10/2` 也得 `5.0` |
| 整除 | `//` | `10 // 3` | 3 | 只要整数部分，舍掉小数 |
| 取余数 | `%` | `10 % 3` | 1 | 除完剩下的"零头" |
| 乘方 | `**` | `2 ** 3` | 8 | 2 的 3 次方 |

> 💡 **整除 `//` 和取余 `%` 是干啥用的？举两个生活例子：**
> - `17 // 5 = 3`：17 个苹果每袋装 5 个，能装满 3 袋。
> - `17 % 5 = 2`：装完 3 袋，还剩 2 个苹果装不下。
> 这俩在后面判断"奇偶数"（`x % 2`）、"分页"时特别有用，先留个印象。

#### 运算也有"先后顺序"

和数学一样，Python 里 `*` `/` 比 `+` `-` 优先，括号最优先：

```python
print(2 + 3 * 4)       # 先算 3*4=12，再 +2 → 14
print((2 + 3) * 4)     # 先算括号 2+3=5，再 *4 → 20
```

> 💡 拿不准就加括号。括号多了不会错，还能让人一眼看懂——这是好习惯。

### 三、把计算结果存起来

光打印不过瘾，我们想把计算结果存进变量，以后反复用。这就用回昨天的变量了：

```python
price = 25          # 一个苹果 25 块（假设是进口苹果🍎）
count = 4           # 买了 4 个
total = price * count   # 先算，存进 total
print(total)        # 显示 100
print("一共花了" + str(total) + "元")
```

看最后一行：`str(total)` 是今天要重点解决的"数字转文字"问题，见下节。

### 四、数字和文字，怎么互相转换？（新手第一个小坎）

回忆 Day 2 的规矩：**有引号的是文字，没引号的是让电脑算的数。**

```python
print("100" + "200")   # 文字拼文字 → 100200（像粘胶布，粘在一起）
print(100 + 200)       # 数字加数字 → 300（真的在算）
```

看出区别了吗？同样是 `+`：
- **文字 + 文字 = 更长文字**（拼接）
- **数字 + 数字 = 求和**（计算）

那如果想把"数字"粘进"一句话"里，比如"一共花了 **100** 元"？直接把数字和文字用 `+` 粘，电脑会报错，因为它不知道你要"拼"还是要"算"。解决办法是：**先把数字变成文字，再拼。**

| 需求 | 用这个 | 例子 | 结果 |
|------|--------|------|------|
| 数字 → 文字 | `str()` | `str(100)` | `"100"`（现在是文字了） |
| 文字 → 整数 | `int()` | `int("100")` | `100`（现在是数字了） |
| 文字 → 小数 | `float()` | `float("3.14")` | `3.14` |

> 💡 `str`、`int`、`float` 这三个名字，就是我们昨天学的三种类型名。把类型名当"转换按钮"用：
> **`类型名(东西)` = 把这个东西变成该类型。** 特别好记！

正确写法示范：

```python
total = 100
print("一共花了" + str(total) + "元")   # ✅ 先把 100 变成"100"，再拼
# print("一共花了" + total + "元")      # ❌ 数字和文字直接拼会报错
```

### ✏️ 今日练习（约 20 分钟）

1. **当计算器**：用 Python 算一道你生活里的账，比如"买 3 斤苹果每斤 5.5 元，共多少钱"，把结果存进变量再打印。
2. **玩整除和取余**：算一算 `25 // 4` 和 `25 % 4`，然后用自己的话解释这两个数分别代表什么（提示：25 个糖分给 4 个小朋友）。
3. **判断奇偶**：用 `% 2` 判断 7 是奇数还是偶数（`7 % 2` 等于几？奇数余数是几？）。
4. **转换练习**：给定 `year = 2026`，打印出一句话"现在是 2026 年"（用 `str()` 帮忙）。再试试 `int("50") + int("60")` 等于多少。

### 📌 今日小结

- 数字两种：**整数 int**（无小数点）、**小数 float**（有小数点）。
- 运算：`+ - * /` 常规，`//` 整除、`%` 取余、`**` 乘方；括号最优先。
- `+` 对文字是"拼接"，对数字是"相加"，别混。
- **`str()` `int()` `float()`** 是把东西在"文字↔数字"间转换的按钮。

## 📅 Day 5 · 字符串：驯服"文字"

> 🎯 **今日目标**：学会对文字做各种操作——取单个字、截一段、拼接、变形、查找。
> 文字处理是 Python 最常用的本事之一（批量改文件名、整理文本都靠它）。

### 一、字符串：就是一串"排好队的字符"

昨天说过，用引号包起来的文字叫**字符串（string，简称 str）**。你可以把它想象成**一列火车，每节车厢是一个字**：

| 索引（从 0 开始） | 这个位置上的字符 |
| --- | --- |
| 0 | h |
| 1 | e |
| 2 | l |
| 3 | l |
| 4 | o |
| -1 | o （倒数第一个，从右往左数） |

每一节车厢（每个字）都有自己的**编号**。但在编程里，编号有个"反常识"的规矩：

> ⚠️ **编号从 0 开始，不从一开始！**
> 第 1 个字编号是 `0`，第 2 个字是 `1`……这是历史惯例，全世界编程语言都这样。
> 刚开始别扭，想通"从 0 数"就顺了。

### 二、取单个字：索引（index）

想知道字符串里某个位置是什么字，用方括号 `[ ]` 写上编号取出来，这叫**索引**：

```python
word = "hello"
print(word[0])   # 第 0 个字 → h
print(word[1])   # 第 1 个字 → e
print(word[4])   # 最后一个字 → o
```

还能**从后往前数**：最后一个字编号是 `-1`，倒数第二是 `-2`：

```python
print(word[-1])   # 最后一个 → o
print(word[-2])   # 倒数第二 → l
```

> 💡 `-1` 取最后一个字，超级常用，请记住。

### 三、截一段：切片（slice）

想一次取"一段连续的文字"，用切片。格式是 `[起点:终点]`：

```python
s = "python编程"
print(s[0:6])    # 从第0个到第6个之前 → "python"
print(s[6:8])    # 从第6个到第8个之前 → "编程"
```

一个口诀帮你记住：**`[起点:终点]`，取"起点"，不取"终点"**（专业说法叫"左闭右开"）。
就像坐公交，从第 0 站上，到第 6 站下，中间经过的站都算，但第 6 站本身不上。

还有几个偷懒写法：

```python
s = "python编程"
print(s[:6])     # 从开头取到第6个前 → "python"（省略起点=从头）
print(s[6:])     # 从第6个取到最后 → "编程"（省略终点=到尾）
print(s[:])      # 全都要 → 整串
```

> 💡 想知道字符串有多长（几个字），用 `len()`（length，长度）：
> `len("python编程")` → `8`（python 占 6 个，编程占 2 个）。

### 四、拼接与重复

- **拼接**（昨天学过）：`"你好" + "世界"` → `"你好世界"`
- **重复**：文字可以用 `*` 重复！`"ab" * 3` → `"ababab"`

```python
print("=" * 20)     # 打印 20 个等号，做个分隔线 → ====================
print("加油" * 2)   # 加油加油
```

### 五、字符串自带很多"超能力"：常用方法

字符串（文字）自带一堆现成的功能，专业叫**方法**。你只要在文字后面点 `.` 再接功能名就能用。介绍 8 个最常用的：

```python
name = " 小明同学 "

# 1. 去掉首尾空白（用户输入常带空格）
print(name.strip())        # "小明同学"

# 2. 全变大写 / 全变小写
print("Hello".upper())     # "HELLO"
print("Hello".lower())     # "hello"

# 3. 替换：把 A 换成 B
print("我喜欢苹果".replace("苹果", "香蕉"))   # "我喜欢香蕉"

# 4. 分割：按某个符号切成几段（得到列表，明天细说列表）
print("苹果,香蕉,葡萄".split(","))   # ["苹果", "香蕉", "葡萄"]

# 5. 查找：某段文字在不在，在的话在第几个位置（不在返回 -1）
print("hello world".find("world"))   # 6
print("hello world".find("abc"))     # -1（没找到）

# 6. 判断是不是纯数字（常用于校验输入）
print("123".isdigit())     # True
print("12a".isdigit())     # False

# 7. 判断以什么开头 / 结尾
print("hello.py".endswith(".py"))    # True（是不是 py 文件？）

# 8. 统计出现次数
print("banana".count("a"))    # 3
```

> 💡 方法不用死记，用到再查。你只要知道"**字符串自带很多现成功能，`.` 后面就是功能名**"，需要时搜一下就有。
> 记住 3 个最常用的即可：`strip()`（去空格）、`replace()`（替换）、`split()`（分割）。

### ✏️ 今日练习（约 20 分钟）

1. **取字**：给定 `city = "上海市"`，取出第 0 个字、最后一个字（用 `-1`）。
2. **切片**：给定 `email = "zhangsan@163.com"`，思考一下：怎么取出 `@` 前面的部分？（提示：先 `find("@")` 知道 @ 在第几位，再切片。）
3. **当清洁工**：用户输入常带空格。把 `"  你好  "` 用 `strip()` 洗干净，打印对比。
4. **做替换**：把句子 `"今天天气真差"` 里的"差"换成"好"，打印出来。
5. **数一数**：`"banana"` 里有几个 `"a"`？用 `count` 数出来。
6. **小挑战**：打印一条由 30 个 `-` 组成的分隔线（用 `*` 重复）。

### 📌 今日小结

- 字符串像一列火车，每节车厢是一个字；**编号从 0 开始**。
- **索引 `[i]`** 取单个字；`-1` 取最后一个。
- **切片 `[起点:终点]`** 取一段，"取起点不取终点"；可省略起点/终点。
- `len()` 数长度；`+` 拼接；`*` 重复。
- 字符串自带很多方法：`strip` `replace` `split` `find` `upper` `lower` 等，`.` 后面调用。

1. `"hello"` 里 `h` 的编号是多少？`o` 用 `-` 几能取到？
2. `"hello"[1:3]` 取出来是哪几个字？
3. `"abc" * 3` 的结果是什么？

## 📅 Day 6 · 列表：一次管理一大堆数据

> 🎯 **今日目标**：学会用"列表"把一堆数据装在一起，并能增、删、查、改。
> 有了列表，你才算能处理"批量"的数据。

### 一、为什么需要列表？

变量一次只装一个值。可现实中你经常要处理"一堆"东西：全班同学的名字、一个月的开销、购物清单……
如果给每个名字都建一个变量 `name1`、`name2`……`name50`，光起名就疯了。

列表（list）就是来解决这个的：**一个盒子，装下任意多个值**，还自动编好号。

### 二、列表长什么样？

用一对方括号 `[ ]`，里面用逗号隔开放一堆值：

```python
fruits = ["苹果", "香蕉", "葡萄", "西瓜"]
```

这就是一个列表，像一列有编号的储物柜：

| 编号（索引） | 柜子里的东西 |
| --- | --- |
| 0 | 苹果 |
| 1 | 香蕉 |
| 2 | 葡萄 |
| 3 | 西瓜 |
| -1 | 西瓜 （最后一个） |

> 💡 列表里的东西可以**五花八门**，数字、文字甚至混着放都行：
> `mixed = [1, "苹果", 3.14, True]` —— Python 不挑食。
> 但实际使用中，一个列表最好装"一类"东西（全是名字、或全是数字），这样更清晰。

### 三、从列表里取东西：和字符串一样用 `[ ]`

昨天学的索引和切片，在列表里**照样管用**：

```python
fruits = ["苹果", "香蕉", "葡萄", "西瓜"]

print(fruits[0])     # 苹果（第0个）
print(fruits[-1])    # 西瓜（最后一个）
print(fruits[1:3])   # ["香蕉", "葡萄"]（取一段）
print(len(fruits))   # 4（列表长度）
```

### 四、增、删、改、查——列表的四大绝活

列表比字符串厉害的是：**它能变**（加东西、减东西、换东西）。这些都要靠列表的"方法"（`.功能名`）来做。

#### ① 增（往列表里加东西）

```python
fruits = ["苹果", "香蕉"]

fruits.append("葡萄")      # 往末尾加一个 → ["苹果","香蕉","葡萄"]
fruits.insert(1, "草莓")   # 插到第1个位置 → ["苹果","草莓","香蕉","葡萄"]
fruits.extend(["西瓜","梨"]) # 把另一个列表整个接上来
```

> 💡 `append`（追加）最常用，记它就够了。

#### ② 删（去掉东西）

```python
fruits = ["苹果", "香蕉", "葡萄"]

fruits.remove("香蕉")       # 按"值"删，删掉香蕉 → ["苹果","葡萄"]
popped = fruits.pop()       # 删掉最后一个，并把它返回给你 → 弹出"葡萄"
del fruits[0]               # 按"位置"删，删掉第0个
```

> ⚠️ `remove` 删的是"内容"，`pop`/`del` 删的是"位置"。分清这两个，就不会删错。

#### ③ 改（换掉某个）

直接用索引赋值，像给储物柜换内容：

```python
fruits = ["苹果", "香蕉", "葡萄"]
fruits[1] = "火龙果"        # 把第1个"香蕉"换成"火龙果"
# 结果：["苹果", "火龙果", "葡萄"]
```

#### ④ 查（在不在？排排序？）

```python
nums = [3, 1, 4, 1, 5, 9, 2, 6]

print(4 in nums)            # 4 在不在列表里？→ True
print(nums.count(1))        # 1 出现了几次？→ 2
nums.sort()                 # 从小到大排序 → [1,1,2,3,4,5,6,9]
nums.sort(reverse=True)     # 从大到小排 → [9,6,5,4,3,2,1,1]
nums.reverse()              # 直接反转顺序
print(sum(nums))            # 求和
print(max(nums), min(nums)) # 最大值、最小值
```

### 五、遍历列表：一个一个挨着看（重点！）

列表最常用的操作，是"从头到尾挨个处理每个元素"，这叫**遍历**。它要和"循环"配合（循环第 10 天细讲），但这行代码你今天就会用：

```python
fruits = ["苹果", "香蕉", "葡萄"]

for fruit in fruits:
    print("我爱吃" + fruit)
```

运行后：

```
我爱吃苹果
我爱吃香蕉
我爱吃葡萄
```

翻译成大白话：`for fruit in fruits` 意思是"**对于 fruits 里的每一个 fruit（挨个来）**"，然后对每一个都执行下面缩进的那行。
就像老师点名，从第一个同学点到最后一个，每点到一个就说一句"我爱吃 XX"。

> ⚠️ **注意冒号和缩进！** `for` 那行末尾要有英文冒号 `:`，下面那行要**往里缩进**（空几格）。
> 缩进在 Python 里是"语法"，不是好看——缩进错了程序就报错。现在照着敲，慢慢体会。

### ✏️ 今日练习（约 20 分钟）

1. **建清单**：创建一个购物清单列表 `shopping = ["牛奶", "鸡蛋", "面包"]`，用 `append` 再加一样"可乐"，打印看看。

### 📌 今日小结

- **列表 = 一列带编号的储物柜**，用 `[ ]` 创建，编号从 0 开始。
- 索引、切片、`len()` 和字符串通用。
- 四大绝活：`append` 增、`remove`/`pop` 删、索引赋值改、`in`/`sort`/`sum` 查。
- `for x in 列表:` 是**遍历**（挨个处理），注意**冒号和缩进**。

## 📅 Day 7 · 字典：给数据"配对"

> 🎯 **今日目标**：学会用"字典"存"成对"的信息。字典是 Python 里最常用、最好用的结构之一。

### 一、列表的"痛点"

列表像一排储物柜，靠**编号（0,1,2…）**找东西。可生活中很多信息，靠编号找很别扭。

比如你想存"小明的信息"。用列表存：

```python
person = ["小明", 18, "男", "北京"]
```

问题来了：过两天你（或别人）看这代码，`person[1]` 到底是年龄还是电话？完全靠猜。
**列表只有位置，没有名字，可读性差。**

### 二、字典：给每样东西贴个"名牌"

字典（dict，全称 dictionary）的诞生就是为了解决这个问题。它存的是**一对一对**的信息——每个值都配一个"名字"：

```python
person = {"姓名": "小明", "年龄": 18, "性别": "男", "城市": "北京"}
```

现在清楚多了！这就是一个字典：

| 键（key，名字） | 值（value，内容） |
|-----------------|-------------------|
| 姓名 | 小明 |
| 年龄 | 18 |
| 性别 | 男 |
| 城市 | 北京 |

> 💡 **字典 = 一本通讯录。** 你查"张三"这个名字，就能找到他的电话。
> 字典里，左边带名字的叫**键（key）**，右边对应的叫**值（value）**。
> **规则：键不能重复**（通讯录里不会有两个一模一样的名字对应不同电话），但值可以重复。

### 三、用字典：靠"键"取"值"

取东西不靠编号了，靠**键的名字**：

```python
person = {"姓名": "小明", "年龄": 18, "城市": "北京"}

print(person["姓名"])   # 小明
print(person["年龄"])   # 18
print(person["城市"])   # 北京
```

> 💡 看，`person["年龄"]` 一目了然是取年龄，比 `person[1]` 强太多了。这就是字典的意义。

#### 增、改、删

```python
person = {"姓名": "小明", "年龄": 18}

person["城市"] = "北京"        # 增加一对：键"城市"原本没有 → 新增
person["年龄"] = 19            # 键"年龄"已存在 → 修改（从18变19）
del person["城市"]             # 删掉"城市"这一对
```

> 💡 记住一个省心规律：**`字典[键] = 值`，键存在就是"改"，键不存在就是"加"。**

#### 安全取值：怕键不存在，用 `get`

如果你取的键**根本不存在**，程序会直接报错"罢工"。想稳妥点，用 `get()`：

```python
person = {"姓名": "小明"}

print(person.get("姓名"))          # 小明
print(person.get("电话"))          # None（没有"电话"这个键，返回 None，不报错）
print(person.get("电话", "未登记"))  # 未登记（没查到就给个默认值）
```

> 💡 `None` 是 Python 里表示"空/没有"的特殊值。`get()` 取不到的键返回 `None`，而不是报错。

### 四、字典的遍历：名字和内容都要看

```python
person = {"姓名": "小明", "年龄": 18, "城市": "北京"}

# 遍历所有的"键"
for key in person:
    print(key)          # 姓名 / 年龄 / 城市

# 遍历所有的"键值对"（推荐，最常用）
for key, value in person.items():
    print(key + "是：" + str(value))
```

运行第二个循环：

```
姓名是：小明
年龄是：18
城市是：北京
```

> 💡 `.items()` 意思是"把每对键值打包一起拿出来"。做"把通讯录里每个人打印出来"这类事，就靠它。

### 五、列表 vs 字典，怎么选？

| | 列表 list | 字典 dict |
|---|-----------|-----------|
| 用什么找 | 编号（0,1,2…） | 键的名字（"姓名"…） |
| 适合存 | **一堆同类**数据 | **成对**的属性信息 |
| 例子 | 全班同学的名单 | 某个同学的详细信息 |
| 长什么样 | `["小明", 18]` | `{"姓名": "小明", "年龄": 18}` |

> 💡 **一个常见组合**：用一个**列表**装很多本**字典**。比如一个班：
> ```python
> students = [
>     {"姓名": "小明", "年龄": 18},
>     {"姓名": "小红", "年龄": 17},
> ]
> ```
> 外层列表管"有几个学生"，内层字典管"每个学生的详细信息"。这是真实项目里极其常见的搭配，先眼熟。

### ✏️ 今日练习（约 20 分钟）

1. **建通讯录**：创建一个字典存你自己的信息（姓名、年龄、城市、爱好至少 4 项），然后分别打印出来。
2. **做增改删**：给你的字典加一项"邮箱"，再把"年龄"改成真实年龄，最后删掉一项，每步都打印看看。
3. **练 get**：取一个你字典里**没有**的键（比如"电话"），先用 `["电话"]` 看它报错，再用 `get("电话")` 看它返回什么。体会 `get` 的好处。
4. **遍历**：用 `for key, value in person.items():` 把你的信息一项项打印成"XX：YY"的形式。
5. **组合拳**：创建一个列表，里面放 2 个同学的字典，用循环把每个同学的"姓名"打印出来。
6. **小挑战**：统计一句话里每个字出现几次（提示：用一个字典，字当键，次数当值，遍历这句话，遇到了就 +1）。

### 📌 今日小结

- **字典 = 通讯录**，存"成对"的信息：**键（名字）+ 值（内容）**，键不能重复。
- 用 `字典[键]` 取值；`字典[键] = 值` 改或加；`del` 删。
- 怕键不存在用 `get()`，它会返回 `None` 或默认值，不报错。
- `.items()` 遍历所有键值对。
- **列表装一堆同类，字典存成对信息；"列表套字典"是常见组合。**

## 📅 Day 8 · 条件判断：让程序"看情况办事"

> 🎯 **今日目标**：学会 `if`，让程序不再一条道跑到黑，而是能"分情况"做不同的事。
> 从今天起，程序开始有"智能"了。

### 一、现实世界，本就充满"如果……就……"

人一天要做无数个判断："如果下雨，就带伞；否则，戴墨镜。"
程序也一样。如果只能从上到下执行，那它只是个"计算器"，不是"智能程序"。
`if`（如果）就是让程序学会**分岔路口**的本事。

### 二、最简单的 if：如果……就……

```python
age = 20

if age >= 18:
    print("你成年了")
```

大白话：如果 `age >= 18`（age 大于等于 18）这件事**成立**，就执行下面缩进的那行。
这里 `age` 是 20，`20 >= 18` 成立，所以打印"你成年了"。

再拆解结构，务必看清：

```python
if  条件:      # ① "如果" + 一个判断条件 + 英文冒号
    要做的事    # ② 缩进！只有条件成立时才做这些事
```

> ⚠️ **两个铁律，从今天开始刻进脑子：**
> 1. `if` 那行**末尾必须是英文冒号 `:`**。
> 2. 下面"要做的事"必须**缩进**（往右空 4 个空格）。缩进表示"这些事归这个 if 管"。
> 不缩进或乱缩进，是新手最高频的报错，没有之一。

### 三、if...else：不是这样就那样

`if` 管"成立时做的事"，`else`（否则）管"不成立时做的事"。二选一，必有一个被执行：

```python
age = 15

if age >= 18:
    print("你成年了")
else:
    print("你还是个小朋友")
```

这里 15 < 18，条件不成立，于是走 `else` 分支，打印"你还是个小朋友"。

> 💡 就像路口的红绿灯：**条件成立走一条路，不成立走另一条路**，总得走一条。

### 四、if...elif...else：三个以上的岔路口

情况不止两种怎么办？用 `elif`（否则如果，= else + if 的合体），可以接很多个：

```python
score = 85

if score >= 90:
    print("优秀")
elif score >= 80:
    print("良好")
elif score >= 60:
    print("及格")
else:
    print("不及格，要加油")
```

运行逻辑是**从上往下挨个问**：
- `85 >= 90`？不成立，跳过。
- `85 >= 80`？成立！打印"良好"，**后面的一律不再看了**。

> 💡 注意 `elif` 的**顺序有讲究**。上面的例子如果把 `>= 60` 放最前面，那 85 一上来就被判成"及格"，大才小用了。
> **判断条件要从"严"到"松"、从"特殊"到"一般"排。** 这是个容易忽视的坑。

### 五、条件的本质：一个"真或假"的问题

`if` 后面跟的"条件"，最终都会被电脑判断成 `True`（真）或 `False`（假），然后决定走不走。
`age >= 18` 就是一个会产生 True/False 的"判断题"。下一课（Day 9）专门讲怎么写这些判断题。

这里先给你看几个现成的：

```python
if True:                 # 永远成立
    print("一定执行")

if False:                # 永远不成立
    print("永远看不到我")

if "苹果" in ["苹果", "香蕉"]:   # "苹果"在不在列表里？在→True
    print("有苹果")
```

### 六、判断也能"嵌套"：if 里套 if

真实逻辑常常要"先判断一层，再判断一层"。比如：先看是不是会员，是的话再看够不够免邮门槛：

```python
is_vip = True
spent = 300

if is_vip:
    print("欢迎会员")
    if spent >= 200:
        print("您已满200，免运费")
```

缩进一层套一层：第二层 `if` 比第一层缩进更多。**缩进层级 = 逻辑层级**，这是 Python 的美，也是初学者的坎。

> 💡 嵌套别超过 3 层，否则人和电脑都会晕。太复杂时，后面学了"函数"会更好地组织。

### ✏️ 今日练习（约 20 分钟）

1. **年龄判断**：输入一个年龄，`>=18` 打印"成年"，否则"未成年"。
2. **评级**：把上面分数的例子，改成你自己的标准（比如 90/75/60 三档），跑一跑。
3. **排队坑**：故意把"及格"的判断 `>= 60` 放到"优秀"`>= 90` **前面**，用 85 分跑一次，看看结果变成什么。体会顺序的重要性，再改回来。
4. **嵌套**：写一个"能不能进游乐园"的判断：身高 `>= 1.2` 且（先不管"且"，先写身高）……再升级：如果身高够，再判断年龄，`>= 12` 可以玩刺激项目。
5. **生活中的 if**：用大白话写出你早上出门的决策树（"如果下雨→带伞，否则如果很晒→戴帽，否则→直接走"）。

### 📌 今日小结

- `if 条件:` 让程序**分情况**办事，条件成立才执行缩进的部分。
- `if / else`：二选一；`if / elif / else`：多选一，**从上往下挨个问，命中就停**。
- 两个铁律：**英文冒号 `:` + 缩进**（新手第一大坑）。
- 条件最终都是 `True`/`False`；`elif` 顺序要从严到松。
- if 可以嵌套，缩进层级 = 逻辑层级，别超过 3 层。

4. 用大白话描述：`if 下雨: 带伞` 这个结构，电脑是怎么决定的？

## 📅 Day 9 · 比较与逻辑：教程序判断"真假"

> 🎯 **今日目标**：掌握写"判断题"的两大工具——比较运算符和逻辑运算符。
> 有了它们，`if` 的条件你就能随心所欲地写了。

### 一、比较运算符：比大小、比等不等

昨天 `if age >= 18:` 里那个 `>=`，就是**比较运算符**。它拿来比两个值，结果一定是 `True` 或 `False`。

全套比较运算符，一张表认全：

| 符号 | 念作 | 例子 | 结果 |
|------|------|------|------|
| `==` | 等于 | `5 == 5` | True |
| `!=` | 不等于 | `5 != 3` | True |
| `>` | 大于 | `5 > 3` | True |
| `<` | 小于 | `5 < 3` | False |
| `>=` | 大于等于 | `5 >= 5` | True |
| `<=` | 小于等于 | `5 <= 4` | False |

> ⚠️ **超级大坑：`==` 和 `=` 完全不是一回事！**
> - `=` 是**赋值**："把右边的装进左边的盒子"（`age = 18`）。
> - `==` 是**比较**："问电脑，两边一样吗？"（`age == 18`，结果是 True/False）。
> 在 `if` 里想判断"是否相等"，必须用 `==`（两个等号）。写成 `if age = 18:` 会直接报错。
> 这是新手 100% 会栽的坑，现在记住，少走弯路。

#### 数字能比，文字也能比

```python
print("abc" == "abc")       # True（内容一样）
print("abc" == "abd")       # False
print("苹果" == "苹果")      # True
print("abc" != "xyz")       # True
print("apple" > "app")      # True（"apple"更长，逐字比到后面还有字符算大）
```

> 💡 文字比较是"逐字按字典顺序"比，理解到这个程度即可，用得少。

### 二、逻辑运算符：把多个判断"拼"起来

一个判断不够用怎么办？比如"进游乐园要**身高够 且 年龄够**"。这就需要**逻辑运算符**把多个判断连起来。有三个：

| 运算符 | 念作 | 规则 | 例子 |
|--------|------|------|------|
| `and` | 且 | 两边**都**为真，结果才真 | 高 and 年龄够 → 都满足才让进 |
| `or` | 或 | 有**一边**为真，结果就真 | 有身份证 or 有护照 → 有一个就行 |
| `not` | 非 | 真假**翻转** | not True → False |

用"过山车门票"的例子：

```python
height = 1.3
age = 10

# and：两个条件都满足才让玩
if height >= 1.2 and age >= 8:
    print("可以玩过山车")

# or：满足其一即可
has_id = True
has_passport = False
if has_id or has_passport:
    print("可以登机")

# not：取反
is_raining = False
if not is_raining:
    print("没下雨，出门不用带伞")
```

> 💡 **记三个词的中文就够了：and=且（都要），or=或（其一），not=非（反转）。**

#### 组合起来，条件可以很强大

```python
# 会员 且 消费满200 且 不是黑名单会员 → 免运费
is_vip = True
spent = 300
is_blacklist = False

if is_vip and spent >= 200 and not is_blacklist:
    print("免运费！")
```

读法：是会员，**且**消费满200，**且不**是黑名单——三个条件全过，才免运费。清晰！

### 三、判断的"优先级"（and 比 or 更"紧"）

当 `and` 和 `or` 一起出现，`and` 优先，就像乘法优先于加法：

```python
# 想表达：A 或 (B 且 C)
# 下面这行，实际会被理解成 (A 或 B) 且 C
if a or b and c:
    ...
```

> 💡 **拿不准就加括号**，把想要的组合框出来，又清楚又不会错：
> `if a or (b and c):` ——一眼就懂。

### 四、真值小抄：谁算"真"，谁算"假"？

`if` 背后要判断"真不真"。除了 `True`/`False`，其他值也有"真假属性"：

| 算"真"的 | 算"假"的 |
|----------|----------|
| `True` | `False` |
| 非 0 的数字（`1`、`-5`、`3.14`） | `0`、`0.0` |
| 非空文字（`"abc"`） | 空文字 `""` |
| 非空列表/字典 | 空列表 `[]`、空字典 `{}` |
| | `None`（空） |

> 💡 最常见用法：**判断一个列表是不是空的**：
> ```python
> cart = []
> if cart:              # 购物车有东西吗？
>     print("去结算")
> else:
>     print("购物车是空的")
> ```

### ✏️ 今日练习（约 20 分钟）

1. **比较练习**：写出判断"年龄正好 18 岁"的条件（提示：用 `==`，别用 `=`）。再写"不是 18 岁"的。
2. **避开大坑**：故意写 `if age = 18:` 运行一次，看报什么错。再把 `=` 改成 `==`，恢复正常。
3. **且/或/非**：设计一个"能申请助学金"的条件（比如：成绩好 **或** 家庭困难，**且** 没违纪），写成 `if`。
4. **优先级**：写 `if a or b and c:`，然后用括号改成 `if (a or b) and c:` 和 `if a or (b and c):`，体会三者区别。
5. **空判断**：创建一个空列表 `tasks = []`，用 `if tasks:` 判断"今天有任务吗"，有就打印"开始干活"，没有就打印"摸鱼"。

### 📌 今日小结

- 比较运算符：`== != > < >= <=`，结果是 True/False。
- **`=` 是赋值，`==` 才是比较**，if 里判相等必须写两个等号！
- 逻辑：`and`（且，都要真）、`or`（或，一真就行）、`not`（非，反转）。
- `and` 比 `or` 优先，拿不准加括号。
- `if 值:` 时，0/空串/空列表/None 算"假"，其余算"真"。

## 📅 Day 10 · 循环 for：让电脑"重复干活"

> 🎯 **今日目标**：掌握 `for` 循环——这是编程最核心的价值之一：
> **把重复劳动交给电脑，人只管歇着。**

### 一、为什么需要循环？

假设要把"我爱吃水果"这句话，对清单里 4 种水果各说一遍。不用循环，你得写 4 遍：

```python
fruits = ["苹果", "香蕉", "葡萄", "西瓜"]
print("我爱吃" + fruits[0])
print("我爱吃" + fruits[1])
print("我爱吃" + fruits[2])
print("我爱吃" + fruits[3])
```

要是清单有 1000 种水果呢？写 1000 遍？**这种蠢事，正是该交给循环的。**

### 二、for 循环：挨个处理

`for` 循环的写法，你在 Day 6 已经见过一面：

```python
fruits = ["苹果", "香蕉", "葡萄", "西瓜"]

for fruit in fruits:
    print("我爱吃" + fruit)
```

四行代码搞定任意长度！运行结果：

```
我爱吃苹果
我爱吃香蕉
我爱吃葡萄
我爱吃西瓜
```

翻译成大白话：`for fruit in fruits:` 意思是"**对于 fruits 里的每一个 fruit（挨个来）**"。
每一轮，`fruit` 就变成清单里的下一个，然后执行下面缩进的代码。

> 💡 `fruit` 这个名字是你自己起的，叫什么都行（`x`、`item`、`水果` 都行）。
> 它是个"临时工"——每轮循环，它就"变身"成当前这一项。循环结束，它就下班了。

#### 循环是怎么"转"起来的？

拿上面例子，电脑内心的活动是这样的：

```
第1轮: fruit = "苹果" → 打印"我爱吃苹果"
第2轮: fruit = "香蕉" → 打印"我爱吃香蕉"
第3轮: fruit = "葡萄" → 打印"我爱吃葡萄"
第4轮: fruit = "西瓜" → 打印"我爱吃西瓜"
没有下一项了 → 循环结束，继续往下走
```

### 三、for 不止能遍历列表

`for` 可以搭配很多"可挨个取"的东西：

```python
# 1. 遍历字符串：一个字一个字来
for ch in "hello":
    print(ch)          # h / e / l / l / o 各占一行

# 2. 遍历字典：默认取"键"
scores = {"语文": 90, "数学": 85}
for subject in scores:
    print(subject)     # 语文 / 数学

# 3. 配合 range()：重复指定次数（超常用！）
for i in range(5):
    print(i)           # 0 1 2 3 4（从0到4，共5次，不含5）
```

> 💡 **`range(n)` 是循环的黄金搭档**，意思是"从 0 到 n-1，挨个来"。
> 想让电脑重复做某事 100 遍，就 `for i in range(100):`，干脆利落。
> 还有 `range(1, 6)` → 1,2,3,4,5（起点到终点前）；`range(0, 10, 2)` → 0,2,4,6,8（步长2）。

### 四、循环里做"累计"：数总和、凑总数

循环最实用的场景之一，是"边跑边记账"——用一个变量，循环外先清零，循环里不断往上加：

```python
prices = [25, 30, 12, 8, 45]

total = 0                 # ① 循环外，先准备一个空盒子
for price in prices:
    total = total + price # ② 每轮把当前价格倒进盒子

print("总价是", total)    # 总价是 120
```

电脑心里的账本：

```
开始: total = 0
+25 → total = 25
+30 → total = 55
+12 → total = 67
+8  → total = 75
+45 → total = 120
```

> 💡 `total = total + price` 意思是"在原来的基础上，再加上 price"。
> 它有个简写：`total += price`，效果一模一样。这是程序员的省事写法，认识即可。

### 五、循环里也能做判断：数个数、挑出来

循环 + 前面学的 `if`，威力巨大：

```python
nums = [3, 10, 7, 22, 5, 18]

count = 0                 # 计数器：数有几个大于10的数
big = []                  # 收集器：把大于10的挑出来

for n in nums:
    if n > 10:
        count += 1
        big.append(n)

print("大于10的有", count, "个")   # 大于10的有 3 个
print("它们是", big)                # 它们是 [22, 18] ...（按出现顺序）
```

这个模式（循环里判断，符合条件的就统计/收集）在真实项目里遍地都是，务必吃透。

### ✏️ 今日练习（约 20 分钟）

1. **基础遍历**：遍历你自己的购物清单，每样打印成"我要买 XX"。
2. **range 练习**：用 `for i in range(5)` 打印 0~4；再用 `range(1, 11)` 打印 1~10。
3. **算总分**：给你 5 门课的成绩列表，用循环算出总分和平均分（平均分 = 总分/科目数）。
4. **数偶数**：用循环 + `if`，数出 1~20 里有多少个偶数（提示：`n % 2 == 0`）。
5. **收集**：把 1~20 里所有**大于 10 且是偶数**的数，收集到一个列表里打印出来。
6. **小挑战**：打印一个"金字塔"——用两层循环，第一层控制行数，第二层控制每行打印几个星号。（做不出来没关系，先想。）

### 📌 今日小结

- `for x in 可挨个取的东西:` 是循环，把重复劳动自动化。**冒号 + 缩进**不能忘。
- 循环变量（如 `fruit`）每轮"变身"成当前项。
- `range(n)` 是循环黄金搭档，控制重复次数。
- "累计/计数"模式：**循环外先准备空盒子，循环里不断更新**。
- 循环 + if = 挑数据、做统计的王道组合。

### 🧠 小测验

1. `for i in range(3):` 会循环几次？`i` 分别是哪几个值？
2. 想遍历一个列表，`for` 后面写 `in` 什么？

## 📅 Day 11 · while 循环：条件不到，就一直转

> 🎯 **今日目标**：掌握 `while` 循环和两个"遥控器"——`break`（立刻停）和 `continue`（跳过这次）。
> 同时学会避开循环最大的坑：死循环。

### 一、for 和 while 的分工

| | `for` 循环 | `while` 循环 |
|---|-----------|--------------|
| 什么时候用 | **知道要循环几次**（遍历清单、range） | **不知道几次，只看条件**（满足就继续） |
| 大白话 | "对每一项都做一遍" | "只要……就一直做" |
| 例子 | 遍历购物车每件商品 | 游戏没结束就一直接受玩家输入 |

### 二、while：只要条件成立，就一直转

```python
count = 1

while count <= 5:
    print("这是第", count, "遍")
    count = count + 1      # 每遍让 count +1，否则会出大事（见死循环）

print("循环结束")
```

运行后打印第 1 遍到第 5 遍，然后因为 `count` 变成 6，`6 <= 5` 不成立了，循环结束。

> ⚠️ **while 的铁律：循环里一定要做一件"能改变条件的事"。**
> 上面例子里，`count = count + 1` 就是在慢慢逼近"条件不成立"。
> 如果忘了写它，`count` 永远是 1，`1 <= 5` 永远成立，程序就会**永远跑下去**——这就是"死循环"。

#### 死循环：新手第二大名场面

```python
# ⚠️ 反面教材：这段会永远打印，停不下来！
while count <= 5:
    print("停不下来了！")
    # 忘了让 count 变化
```

> 💡 万一真写出死循环、程序卡住了，别慌：
> - 在线编辑器：点"停止"按钮。
> - VS Code / 命令行：按 `Ctrl + C`（Mac 也是 `Ctrl + C`）强制中断。
> 然后回去检查：循环里是不是少了"改变条件的那一步"。

### 三、break：看情况不对，立刻喊停

`break` 一出现，**整个循环马上结束**，不管条件还成不成立。就像玩游戏时按下"退出"键。

最经典的用途：**找到了就停**，不用再傻傻找下去。

```python
nums = [3, 7, 10, 22, 5]
target = 10

for n in nums:
    if n == target:
        print("找到", target, "了！")
        break                 # 找到了，后面的 22、5 不用再看了
    print("正在看", n)
```

运行：

```
正在看 3
正在看 7
找到 10 了！
```

看见没？找到 10 后立刻 `break`，连"正在看 22"都没打印。**这就是 break 的价值：省时间。**

### 四、continue：这次不算，直接下一次

`continue` 和 `break` 不同——它只是**跳过这一次**，循环继续。像点名时这个人跳过了，下一个人照点。

```python
# 打印1到10，但跳过所有偶数
for i in range(1, 11):
    if i % 2 == 0:      # 是偶数
        continue        # 跳过这次，不打印
    print(i)            # 只打印奇数
```

结果：`1 3 5 7 9`。遇到偶数就 `continue` 跳过，奇数的才打印。

> 💡 **break 和 continue 一句话分清：**
> - `break` = "整个循环，到此为止"（掀桌子走人）。
> - `continue` = "这一次不算，继续下一轮"（这题跳过，做下一题）。

### 五、while + break：非常实用的组合

"while + break"是写交互程序的标准套路。比如让用户反复输入，输入"退出"才结束：

```python
while True:                          # True 恒真，看似死循环，但有 break 兜底
    answer = input("猜一个数字（输入 q 退出）：")
    if answer == "q":
        print("欢迎下次再来")
        break                        # 用户要退出，立刻结束
    print("你输入的是", answer)
```

> 💡 `input("提示语")` 是让程序**停下来等你打字**的命令，回车后把你输入的返回。
> `while True: ... break` 是个常见模式：先用 `True` 让循环一直转，内部用 `break` 在合适时机退出。别被 `True` 吓到，有 break 就不怕死循环。

### ✏️ 今日练习（约 20 分钟）

1. **数数**：用 `while` 从 1 数到 10，每个数打印一行。
2. **躲死循环**：故意写一个没有 `count = count + 1` 的 while，运行几秒后用 `Ctrl+C` 或停止按钮中断它。亲眼见识死循环，以后就会防了。
3. **找东西**：给定列表 `[5, 8, 13, 21, 34]`，用 `for` 找到第一个大于 10 的数就 `break`，打印它。
4. **跳偶数**：用 `continue` 打印 1~20 的所有奇数。
5. **交互小demo**：用 `while True + input + break` 写一个程序：反复问你"今天开心吗(y/n)"，输入 `n` 就退出，输入别的就再问。
6. **小挑战**：写一个"密码验证"：正确密码是 `"8888"`，用 while 让用户反复输入，输对 `break` 打印"登录成功"，最多试 3 次（提示：加个计数器）。

### 📌 今日小结

- `while 条件:` 只要条件成立就一直转，适合"不知道循环几次"的场景。
- **while 铁律：循环体里必须做"能改变条件"的事**，否则死循环。
- `break` = 立刻结束整个循环（找到即停）；`continue` = 跳过这次、继续下一轮。
- `input()` 等待用户输入；`while True + break` 是写交互程序的常用套路。

## 📅 Day 12 · 综合练习：做一个"猜数字"小游戏

> 🎯 **今日目标**：把前 11 天学的变量、if、循环、break 全部用上，做出你的**第一个完整小游戏**。
> 做完这个，你对"编程"的理解会上一个大台阶。

### 一、先规划：把大问题拆成小步骤

还记得 Day 1 的程序员思维吗？——**先拆解，再动手**。我们先不写代码，用大白话设计游戏规则：

> 电脑心里想一个 1~100 的数。
> 你来猜，电脑提示"大了"或"小了"。
> 猜中为止，告诉你一共猜了几次。

### 二、设计思路（先想清楚，再写代码）

把这个游戏拆成几步：

1. **准备阶段**：电脑要先"想好"一个秘密数字。
2. **循环**：因为要反复猜，所以要有个循环，猜中才停。
3. **输入**：每轮让玩家输入一个数。
4. **判断**：拿玩家猜的，和秘密数字比：
   - 猜大了 → 提示"大了"
   - 猜小了 → 提示"小了"
   - 猜中了 → 恭喜 + 结束循环
5. **统计**：数一数玩家一共猜了几轮。

> 💡 看出来了吗？**判断用 `if`，反复猜用循环，输入用 `input`，猜中退出用 `break`。**
> 前面学的每一样，这里都用上了。这就是"综合练习"的意义。

### 三、认识一个新朋友：random（随机）

游戏需要一个"秘密数字"，而且每次玩最好不一样，这就用到**随机数**。
Python 有个现成的工具箱叫 `random`，我们借用一下：

```python
import random                       # 把 random 工具箱请出来

secret = random.randint(1, 100)     # 随机生成一个 1~100 的整数
print("电脑想好了一个数（范围1-100）")  # 调试时可打开看看是不是这个数
```

> 💡 `import random` 是"导入一个工具箱"（第 18 天会专门讲）。
> `random.randint(1, 100)` 就是"随机给我一个 1 到 100 之间的整数"。
> 现在不用深究，会用即可——**编程很重要的能力，就是会"借"现成的工具。**

### 四、完整代码（逐行带注释）

```python
import random

# 1. 准备：电脑想一个秘密数字
secret = random.randint(1, 100)
times = 0                      # 猜了几次，先归零

print("===== 猜数字游戏开始 =====")
print("我想好了一个 1~100 的数，来猜吧！")

# 2. 循环：一直猜，直到猜中
while True:
    guess = input("你猜是几：")     # 3. 等玩家输入
    guess = int(guess)              # 输入的是文字，转成数字才能比较
    times = times + 1               # 每猜一次，次数+1

    # 4. 判断：拿玩家猜的和秘密数字比
    if guess > secret:
        print("大了！往小了猜")
    elif guess < secret:
        print("小了！往大了猜")
    else:
        # 5. 猜中了
        print("恭喜你，猜对了！答案就是", secret)
        print("你一共猜了", times, "次")
        break                       # 猜中了，结束循环
```

### 五、逐段讲解（这段最重要）

**① `guess = input(...)` 再到 `guess = int(guess)`**
`input` 得到的永远是**文字**。比如玩家敲 `50`，电脑收到的是文字 `"50"`。
文字 `"50"` 不能和数字 `secret` 比大小，所以要用 `int()` 转成数字 `50`。（Day 4 学的，用上了！）

**② `times = times + 1`**
每猜一次就累加，最后告诉玩家"你猜了 N 次"。（Day 10 学的计数模式，用上了！）

**③ `if / elif / else` 三兄弟**
三种情况：大了、小了、正好。注意**顺序**：先比 `>`，再比 `<`，最后 `else` 就是"正好"。（Day 8 学的，用上了！）

**④ `break`**
猜中后必须 `break`，否则循环不会停，还会让你一直猜。（Day 11 学的，用上了！）

## 📅 Day 13 · 函数：把代码打包成"菜谱"

> 🎯 **今日目标**：理解并会写"函数"——把一堆完成某任务的代码打包起来，起个名字，随时调用。
> 函数是程序员的"乐高积木"，是写出大程序的关键。

### 一、没有函数的痛苦

假设你的程序里，有三个地方都要"向用户问好"：

```python
print("你好，欢迎使用！")
# ...中间隔了50行...
print("你好，欢迎使用！")
# ...又隔了50行...
print("你好，欢迎使用！")
```

问题是：哪天想把问候语从"你好"改成"Hi"，你得改 3 个地方，万一漏改一个，程序就"人格分裂"了。
**重复的代码是万恶之源**——写起来累、改起来险、读起来晕。

### 二、函数：一份可以反复用的"菜谱"

函数（function）就是解决这个的：**把一段代码打包，起个名字，以后喊名字就能用。**

打个比方——菜谱。你写下"番茄炒蛋"的步骤，放进抽屉。以后每次想吃，不用重新想步骤，拿出这张菜谱写着做的就行。而且给不同的食材，能炒出不同的蛋。

Python 里定义一个函数，用 `def`（define，定义）：

```python
def greet():
    print("你好，欢迎使用！")
```

解剖一下：

```python
def   greet():          # def + 函数名 + 英文冒号
    print("你好，欢迎使用！")   # 缩进：这些是这个函数的"身体"
```

- `def`：告诉电脑"我要定义一个函数了"。
- `greet`：函数名（你自己起，规矩和变量名一样，见名知意）。
- `( )`：放"原料"的地方（下一天细讲）。
- `:` 和缩进：老规矩，**冒号 + 缩进**表示"以下归这个函数管"。

> ⚠️ **注意：定义了函数，不等于执行了它！**
> 就像写好菜谱，不等于吃到了菜。你得**"调用"（call）**它——喊它的名字。

### 三、调用函数：喊名字，就开工

```python
def greet():
    print("你好，欢迎使用！")

greet()      # ← 调用：喊名字，执行函数里的代码
greet()      # ← 再喊一次，再执行一遍
```

运行结果：

```
你好，欢迎使用！
你好，欢迎使用！
```

现在，问候语只写在函数里**一处**。想改，只改那一处，三个调用点全都跟着变。**一处修改，处处生效**——这就是函数的价值。

### 四、函数为什么是"程序员的乐高"

因为你可以把功能一块块写好，再拼成复杂程序。就像：

```python
def 开门():
    print("开门")

def 点火():
    print("点火")

def 炒菜():
    print("炒菜")

def 做一顿饭():
    开门()      # 函数里可以调用别的函数
    点火()
    炒菜()
    print("开饭！")

做一顿饭()     # 喊一声"做一顿饭"，里面的步骤自动按序执行
```

> 💡 看出来了吗？`做一顿饭` 是个函数，它内部又调用了 `开门`、`点火`、`炒菜` 三个函数。
> **这就是"抽象"——把复杂的做菜过程，打包成一个简单动作。** 大程序都是这么一层层搭起来的。

### 五、一个函数的"自我修养"

好函数有两条军规，从第一天写函数就养成：

1. **一个函数，只做一件事。** `做一顿饭` 里混着"买菜、洗碗、炒菜"就乱套了。拆成一个个小而清晰的函数。
2. **见名知意。** `greet` 一看就懂是"问候"；`f`、`a`、`x1` 这种名字，三天后你自己都不认识。

> 💡 程序界有句名言：**"写代码时，把你面前的同事当成一个脾气暴躁、知道你住哪的人。"**
> 意思是要把代码写得清晰、有礼貌、易读。好名字和注释，就是对同事的礼貌。

### ✏️ 今日练习（约 20 分钟）

1. **第一个函数**：定义一个 `show_intro()` 函数，里面打印三行自我介绍的话，然后在下面调用它两次。
2. **体验好处**：先写三行重复的问候语，运行；再改写成 `greet()` 函数 + 三次调用，运行。对比两种写法，体会"改一处"的爽感。
3. **乐高拼接**：定义 `打印分隔线()`、`打印标题()`、`打印结尾()` 三个函数，再写一个 `生成报告()` 函数，内部依次调用它们，拼出一份像模像样的"报告"。
4. **改造猜数字**（选做）：把 Day 12 猜数字游戏的"打印欢迎语"部分，抽出来做成一个函数。

### 📌 今日小结

- 重复代码是万恶之源，函数是解药：**把代码打包、起名、复用**。
- `def 函数名():` + 缩进 定义函数；喊 `函数名()` 才是调用执行。
- **定义 ≠ 执行**，必须调用才跑。
- 函数里可以调用别的函数，层层抽象，这是搭大程序的基础。
- 函数军规：**只做一件事 + 见名知意**。

## 📅 Day 14 · 参数与返回值：会定制、会交货的函数

> 🎯 **今日目标**：让函数能"收原料"（参数）和"端出成品"（返回值）。
> 这是从"会用函数"到"会设计函数"的关键一步。

### 一、参数：给函数"递原料"

昨天的 `greet()` 只会说固定的"你好"。可现实中，你想跟不同的人问好："你好，小明"、"你好，小红"……
总不能给每个人写一个函数吧？这就需要**参数**——调用函数时，把"原料"递进去。

```python
def greet(name):              # name 是"参数"，一个等着被填的空位
    print("你好，" + name)

greet("小明")      # 调用时递进"小明" → 打印：你好，小明
greet("小红")      # 递进"小红"   → 打印：你好，小红
```

看，**一个函数，因为参数不同，干出了不同的活。** 就像同一张菜谱，放鸡蛋是番茄炒蛋，放牛肉是黑椒牛柳。

#### 解剖"参数的流动"

```python
def greet(name):   # 定义时：name 是个"占位符"，还没有具体值
    print("你好，" + name)

greet("小明")       # 调用时：把"小明"这个值，递给 name
```

| 术语 | 位置 | 大白话 |
|------|------|--------|
| 参数（parameter） | 定义函数时 `def greet(name)` | 声明的"空位/原料名" |
| 实参（argument） | 调用函数时 `greet("小明")` | 真正递进去的具体值 |

> 💡 这两个词（参数/实参）不用死抠，知道"定义时空位叫参数，调用时真值叫实参"即可。日常都说"参数"。

#### 多个参数：递好几样原料

```python
def introduce(name, age):          # 两个空位
    print("我叫" + name + "，今年" + str(age) + "岁")

introduce("小明", 18)   # 按顺序递：name="小明", age=18
introduce("小红", 17)   # name="小红", age=17
```

> ⚠️ 多个参数**按位置对号入座**：第一个实参给第一个形参，第二个给第二个。顺序别乱。
> （也有关键字参数等进阶写法，现阶段先掌握"按顺序传"。）

### 二、返回值：让函数"端出成品"

到目前为止，函数只会自己 `print`（自言自语）。可很多时候，我们想让函数**算出一个结果交回来**，我们再拿这个结果去用。这就是**返回值**，用 `return`：

```python
def add(a, b):
    return a + b        # 算完 a+b，把结果"交还"给调用者

result = add(3, 5)      # add 把 8 交回来，存进 result
print(result)           # 8
print(result * 2)       # 16——拿到结果还能继续用！
```

对比一下 print 和 return 的区别，这是**新手必须跨过的一道坎**：

| | `print(x)` | `return x` |
|---|-----------|-----------|
| 干了什么 | 把 x **显示**在屏幕上 | 把 x **交还**给调用者 |
| 结果能留着用吗 | ❌ 显示完就"扔"了 | ✅ 能存进变量、继续参与运算 |
| 像什么 | 厨师喊一嗓子"菜好了" | 厨师把菜端到你桌上 |

> 💡 **关键认知：会 print 的函数是"播音员"，会 return 的函数才是"生产力"。**
> 你要的是它**算出的值**，不是它在屏幕上喊的那一嗓子。所以做计算、处理数据的函数，几乎都要 `return`。

#### return 还有个隐藏功能：立刻结束函数

`return` 一执行，函数**马上结束**，后面的代码不再执行：

```python
def check_age(age):
    if age >= 18:
        return "成年"       # 到这儿就交卷、走人
    return "未成年"         # 上面没return，才会走到这

print(check_age(20))   # 成年
print(check_age(15))   # 未成年
```

这个"提前交卷"的技巧，后面写判断逻辑会很常用。

### 三、把"猜数字"改造成函数（学以致用）

还记得 Day 12 的游戏吗？我们把它核心的"猜一次、给提示"的逻辑，抽成一个函数：

```python
def give_hint(guess, secret):
    """根据猜测给出提示：大了/小了/对了"""
    if guess > secret:
        return "大了"
    elif guess < secret:
        return "小了"
    else:
        return "对了"
```

然后主程序就能反复"调用"它。这就是把代码**模块化**——每块各司其职，主逻辑清爽好读。

> 💡 `"""..."""` 叫文档字符串（docstring），是函数的"说明书"，写在这个函数干嘛用的。
> 好习惯，从现在就养成。

### ✏️ 今日练习（约 20 分钟）

1. **问好函数**：给 `greet` 加参数，能对任何人问好；调用三次，问候三个不同的人。
2. **计算器函数**：写 `add(a,b)`、`minus(a,b)`、`multiply(a,b)` 三个函数，都要 `return` 结果，然后打印 `add(4,6)` 和 `multiply(3,9)` 的结果。
3. **print vs return**：写两个函数，一个只 `print` 结果，一个 `return` 结果。分别调用，看看 `f1(2,3) * 10` 和 `f2(2,3) * 10` 哪个能算、哪个会报错。体会 return 的价值。
4. **面积函数**：写 `area(length, width)` 返回矩形面积，再用它算几个不同矩形的面积。
5. **改造游戏**（选做）：把 Day 12 猜数字里"给提示"的部分，按上面的例子抽成 `give_hint` 函数。

### 📌 今日小结

- **参数**让函数可定制：定义时写"空位"，调用时递"真值"，按位置对号入座。
- **`return` 把结果交还给调用者**，能存能用；`print` 只是显示，用完即弃。
- 做计算的函数几乎都要 `return`；`return` 还会让函数**立刻结束**。
- `"""文档字符串"""` 给函数写说明书，好习惯从早养成。
- 把代码抽成函数 = 模块化，主逻辑更清爽。

## 📅 Day 15 · 读懂报错：学会自己"修 bug"

> 🎯 **今日目标**：不再害怕满屏的红色报错，能看懂最常见的几类报错，并掌握"调试"的基本方法。
> **能自己解决报错，是你从"跟着抄"走向"独立写"的分水岭。**

### 一、心态先摆正：报错是朋友，不是敌人

新手看到报错，第一反应是"我完了/我不适合编程"。**大错特错。**

> 💡 **真相：程序员 30% 的时间在写代码，70% 的时间在修 bug。** 资深工程师每天也被报错砸。
> 报错不是说你笨，它其实是电脑在**尽职尽责地告诉你哪里出了问题**。它是线索，是路标，是游戏里的提示音。
> **一个从不报错的程序员，比一个从不犯错的学生更可疑。**

### 二、报错长什么样？怎么读？

报错通常会甩给你一段信息，别被吓到，抓两个关键点就行：

```
Traceback (most recent call last):
  File "test.py", line 5, in <module>
    print(naem)
NameError: name 'naem' is not defined
```

你只需要看两处：

| 看哪里 | 上面例子 | 告诉你什么 |
|--------|----------|-----------|
| **最后一行** | `NameError: name 'naem' is not defined` | **错误类型** + 具体原因 |
| **倒数几行的 line** | `line 5` | 错误大概在**第几行** |

> 💡 阅读顺序：**先看最后一行是什么错，再看它指向第几行。** 90% 的问题能靠这两招定位。

### 三、新手五大经典报错（对号入座）

下面这些是新手几乎必然会遇到的，认脸就行，以后见到能会心一笑："哦，又是你"。

#### ① NameError：名字拼错了 / 没定义

```
NameError: name 'naem' is not defined
```
**病因**：用了一个没定义过的变量，或者拼写错了（`naem` 应为 `name`）。
**药方**：检查拼写，确认这个变量之前 `=` 创建过。

#### ② SyntaxError：语法写错了

```
SyntaxError: invalid syntax        （语法无效）
SyntaxError: unexpected EOF       （括号/引号没闭合）
```
**病因**：漏了英文冒号 `:`、漏了引号、括号没成对、中英文标点混用。
**药方**：看它指的 line，检查那行的冒号、引号、括号。**这是新手最高频的错。**

#### ③ IndentationError：缩进不对

```
IndentationError: expected an indented block   （这里该缩进却没缩进）
```
**病因**：`if`/`for`/`def` 下面该缩进的没缩进，或缩进多少不一致。
**药方**：统一用 4 个空格缩进，别 Tab 和空格混用。

#### ④ TypeError：类型用错了

```
TypeError: can only concatenate str (not "int") to str
```
**病因**：文字和数字直接相加（`"我有" + 5`）、或者拿文字当数字算。
**药方**：想起 Day 4！用 `str()` / `int()` 转换。报错信息其实已经告诉你"str 和 int 不能直接拼"。

#### ⑤ IndexError / KeyError：越界 / 键不存在

```
IndexError: list index out of range    （列表编号超范围了）
KeyError: '电话'                        （字典里没这个键）
```
**病因**：列表只有 3 个，你取了第 10 个；字典没有"电话"键，你却 `["电话"]`。
**药方**：确认长度/键存在；取字典用 `.get()` 更安全（Day 7 学过）。

### 四、调试三板斧（定位问题的套路）

报错信息指向的行，不一定就是"犯错"的行（可能是它上游出的问题）。教你三招系统性地找：

#### 第一板斧：看报错最后一行 + 行号
先读错误类型和位置，很多问题到这步就解决了。

#### 第二板斧：print 大法（最朴实、最有效）
在怀疑的地方，用 `print` 把变量的值打出来看看，和你想的是否一致：

```python
def calculate(prices):
    total = 0
    for price in prices:
        total = total + price
    print("调试：目前 total =", total)   # 加一行，看看每步对不对
    return total
```

> 💡 别小看 `print` 调试，即便是资深工程师也用。它的本质是"**把程序的内心活动暴露给你看**"。
> 觉得哪里可疑，就在那前后 print 一下，往往一看就发现"哦，原来这个变量不是我以为的值"。

#### 第三板斧：缩小范围（二分法）
程序长、不知道哪儿错，就"注释掉一半"跑一跑：
- 还报错 → 问题在这一半；
- 不报错 → 问题在另一半。
再在有问题的那半里继续对半分。几下就能锁定"案发现场"。

## 📅 Day 16 · 文件读写：让数据"存"下来

> 🎯 **今日目标**：学会把数据写进文件、再从文件读出来。
> 到这天，你的程序终于能"记住东西"了——关机重开，数据还在。

### 一、为什么需要文件？

到目前为止，程序里的数据都活在**内存**里。内存有个特点：**断电就没**。程序一关，你辛苦算的东西烟消云散。

> 生活类比：内存像你的**大脑**，思考时用，但睡一觉（关机）可能就忘；
> 文件像**笔记本**，记下来就能长期保存。

想让数据跨程序、跨时间地留存（记账、存配置、保存游戏进度），就得写进**文件**。

### 二、写文件：把内容存进笔记本

用 `open(文件名, 模式)` 打开文件，写入后关闭。基本套路：

```python
# 打开一个叫"笔记.txt"的文件，用"写入"模式
f = open("笔记.txt", "w", encoding="utf-8")   # w = write 写入

f.write("第一行笔记\n")        # 往里写内容
f.write("Python 其实不难\n")

f.close()                     # 用完一定要关，相当于"合上笔记本+保存"
```

跑完后，你的程序所在文件夹，就多了一个 `笔记.txt`，里面是你写的两行字。

> 💡 `\n` 是"换行符"，告诉电脑"到这里换一行"。不写 `\n`，所有内容会挤成一大坨。
> `encoding="utf-8"` 是指定用 UTF-8 编码保存，这样中文不会变成乱码（天书）。**在中文 Windows 上尤其重要，建议养成写它的习惯。**

> ⚠️ **`"w"` 模式的坑：它会"清空重写"！**
> 如果文件里本来有内容，用 `"w"` 打开再写，旧内容会被**覆盖**。
> 想在末尾追加，用 `"a"`（append，追加）模式：
> ```python
> f = open("笔记.txt", "a", encoding="utf-8")
> f.write("这是新追加的一行\n")
> f.close()
> ```

| 模式 | 作用 | 小心 |
|------|------|------|
| `"w"` | 写入（清空原来的） | ⚠️ 会覆盖旧内容 |
| `"a"` | 在末尾追加 | 不动旧内容 |
| `"r"` | 读取（默认） | 文件不存在会报错 |

### 三、读文件：把笔记本翻开

```python
f = open("笔记.txt", "r", encoding="utf-8")

content = f.read()      # 一次读完整个文件
print(content)

f.close()
```

也能**一行一行读**（文件大时更省内存）：

```python
f = open("笔记.txt", "r", encoding="utf-8")
for line in f:
    print("读到一行：", line.strip())   # strip 去掉行尾的换行符
f.close()
```

> 💡 `for line in f:` 一次读一行——这不就是 Day 6 学的列表遍历吗？文件也能被 for 循环一行行"挨个处理"。知识是相通的！

### 四、更优雅的写法：with（自动开关）

每次写都要 `open` + 用完 `close`，万一中间出岔子忘了 `close`，文件可能损坏。
Python 提供了 `with`，能**自动帮你开和关**，省心又安全：

```python
# 写：with 开头，缩进块里操作，退出自动关闭
with open("笔记.txt", "w", encoding="utf-8") as f:
    f.write("用 with 写文件\n")
    f.write("不怕忘关文件\n")

# 读：
with open("笔记.txt", "r", encoding="utf-8") as f:
    content = f.read()
    print(content)
```

> 💡 **以后请都用 `with` 这种写法。** 它更安全（异常也会关文件）、更简洁（不用手动 close）。
> 这是专业人士的标准做法，从今天起养成习惯。

### 五、实战：一个"记账本"小程序

把前面学的全用上：能记一笔账、能查看所有账目。

```python
def 记一笔():
    with open("账本.txt", "a", encoding="utf-8") as f:
        item = input("买了什么：")
        money = input("花了多少钱：")
        f.write(item + " " + money + "元\n")
    print("记好了！")

def 看账本():
    print("===== 历史账目 =====")
    with open("账本.txt", "r", encoding="utf-8") as f:
        for line in f:
            print(line.strip())     # strip 去掉每行末尾换行

# 主程序
while True:
    print("\n1. 记一笔   2. 看账本   3. 退出")
    choice = input("选哪个：")
    if choice == "1":
        记一笔()
    elif choice == "2":
        看账本()
    elif choice == "3":
        break
```

> 💡 这个程序把**函数（Day 13/14）+ 循环（Day 11）+ 判断（Day 8）+ 文件（今天）+ input** 全串起来了。
> 跑一跑，记几笔，退出，再打开看账本——**你会发现数据真的"活"过了关机**。这种成就感，就是继续学下去的动力。

### ✏️ 今日练习（约 20 分钟）

1. **写文件**：创建一个 `hello.txt`，用 `with` 写三行你想说的话。
2. **读文件**：再写一段代码，把 `hello.txt` 读出来打印。
3. **追加**：再往 `hello.txt` 追加一行，重新读取，确认没被覆盖。
4. **踩坑**：先用 `"w"` 模式写一句，再用 `"w"` 模式写另一句，读出来看看第一句还在不在（体会覆盖）。然后改用 `"a"` 再试一次。
5. **行遍历**：给你的文件写一个 `for line in f:` 的读取，给每行加上行号打印。
6. **实战**：把上面的"记账本"完整敲出来跑通，记 3 笔账，退出重进，看账本还在不在。

### 📌 今日小结

- 内存断电就没，**文件**才能长期保存数据。
- `open(名, 模式)`：`"w"` 写（会覆盖！）、`"a"` 追加、`"r"` 读。
- `\n` 换行；中文务必加 `encoding="utf-8"` 防乱码。
- **推荐 `with open(...) as f:`**，自动关闭更安全。
- 文件也能被 `for line in f:` 一行行遍历。

## 📅 Day 17 · 异常处理：给程序"上保险"

> 🎯 **今日目标**：学会用 `try/except` 接住报错，让程序遇到意外时不"崩溃"，
> 而是优雅地提示用户。这是专业程序和"玩具程序"的区别之一。

### 一、一个真实场景：用户不按套路出牌

假设你在记账本里让用户输入金额。用户老老实实输入 `25` 没问题，可万一他手滑输入了 `abc`，或者干脆回车不输：

```python
money = input("花了多少钱：")
money = int(money)      # 用户输入"abc"，这行会"轰"地崩掉
```

程序会甩出一大段 `ValueError` 报错，然后**整个程序挂掉**。用户体验极差："我就输错个字符，你至于死机？"

> 💡 真实世界的用户，总会以你想不到的方式"折腾"程序。**好程序要经得起用户的胡来。**
> 异常处理，就是给程序买的"保险"。

### 二、try / except：try着来，出事我兜底

```python
try:
    money = int(input("花了多少钱："))
    print("你花了", money, "元")
except ValueError:
    print("别闹，请输入一个数字！")
```

运行逻辑：

- **`try`（试一试）块**：把"可能会出错的代码"放进去。
- **`except`（除了…之外）块**：如果 try 里真出错了，**不崩溃**，转来执行这里的代码。

现在用户输入 `abc`，程序不会死，而是淡定地打印"别闹，请输入一个数字！"。稳！

> 💡 类比：`try` 像走钢丝时**系了安全绳**（except）。平时正常走，万一掉下去，安全绳兜住，不摔死，还能换个姿势再来。

### 三、抓具体的"异常类型"

`except` 后面可以指定只抓**某一种**错，不同错不同处理：

```python
try:
    num = int(input("输入一个数："))
    result = 100 / num
    print("100 除以它是", result)
except ValueError:
    print("这不是数字！")
except ZeroDivisionError:
    print("不能除以 0 呀！")
```

- 输入 `abc` → `ValueError` → "这不是数字！"
- 输入 `0` → `ZeroDivisionError` → "不能除以 0 呀！"

> 💡 还记得 Day 15 的五大报错吗？`ValueError`、`ZeroDivisionError`、`IndexError`……这些名字，就是 `except` 后面要写的"异常类型"。
> **认脸报错 + 抓异常**，前后知识在这里打通了。

### 四、except 还能抓"错误信息本身"

```python
try:
    n = int(input("输入数字："))
except ValueError as e:                # as e 把错误信息存进 e
    print("出错了，详情是：", e)        # 把电脑的原话也亮出来
```

`as e` 能拿到报错的具体内容，方便你排查或给用户更精确的提示。

### 五、else 和 finally：锦上添花

```python
try:
    n = int(input("输入数字："))
except ValueError:
    print("不是数字！")
else:
    # try 没出错，才会执行这里
    print("转换成功，你输入的是", n)
finally:
    # 不管出不出错，最后一定执行这里（常用于"收尾/清理"）
    print("程序结束")
```

| 块 | 什么时候执行 |
|----|-------------|
| `try` | 先试这里的代码 |
| `except` | try 出错了才来这 |
| `else` | try **没出错**才来这 |
| `finally` | 无论如何最后都来这（比如关闭文件、释放资源） |

### 六、给记账本上保险（实战）

把 Day 16 的记账本升级，让用户输错金额不再崩溃：

```python
def 记一笔():
    try:
        money = int(input("花了多少钱："))
    except ValueError:
        print("金额必须是数字，这笔没记成。")
        return                      # 出错就返回，不往下走
    with open("账本.txt", "a", encoding="utf-8") as f:
        item = input("买了什么：")
        f.write(item + " " + str(money) + "元\n")
    print("记好了！")
```

现在用户输错金额，程序只会温柔提示，然后等他重新操作，不会"死"给你看。

> ⚠️ **一个提醒：别滥用 try。**
> 不要把一大段代码无脑全塞进 `try` 里指望它兜底。try 只包"**你知道可能出错、且能优雅处理**"的那一小段。
> 到处乱 try，会把真正的 bug 也藏起来，反而难排查。

### ✏️ 今日练习（约 20 分钟）

1. **防崩**：写一个程序让用户输入两个数做除法，用 `try/except` 分别处理"不是数字"和"除数是0"两种情况。
2. **抓信息**：用 `except ValueError as e:` 把错误原话打印出来，看看电脑到底说了啥。
3. **else/finally**：给上面的除法程序加上 `else`（成功时提示结果）和 `finally`（无论如何都打印"计算结束"）。
4. **升级记账本**：把你 Day 16 的记账本，给输入金额的地方加上 `try/except`，输错不再崩溃。
5. **小挑战**：写一个"安全取列表元素"的函数：给定列表和索引，用 try/except 处理 `IndexError`，越界时返回提示而不是崩溃。

### 📌 今日小结

- 用户总会不按套路出牌，好程序要**经得起胡来**。
- `try` 放可能出错的代码，`except` 接住错误、优雅处理，程序不崩溃。
- `except 异常类型:` 分类处理；`as e` 拿到错误详情。
- `else`（没错才执行）、`finally`（无论如何都执行）按需使用。
- try 只包"可能出错的一小段"，别滥用，别把真 bug 藏起来。

## 📅 Day 18 · 模块与第三方库：站在巨人肩膀上

> 🎯 **今日目标**：理解"模块/库"是什么，学会 `import` 借力，会用 `pip` 安装第三方库。
> 这是 Python 最迷人的地方——**你不用从零造轮子。**

### 一、模块：别人打包好的"工具箱"

你已经在 Day 12 用过 `import random` 了。当时说"先借用，第 18 天细讲"，就是今天。

> **模块（module）就是别人写好的一组功能，打包成一个文件，你 `import` 过来就能用。**
> 就像你做饭不用自己炼铁造锅，直接买现成的锅。编程也一样，大量常用功能早有高手写好，白嫖即可。

Python 自带一堆"官方工具箱"（叫**标准库**），安装 Python 时就送你了。几个超好用的：

```python
import random
print(random.randint(1, 6))       # 掷骰子：随机1~6

import datetime
print(datetime.date.today())      # 今天几号

import math
print(math.sqrt(16))              # 开平方：4.0
print(math.pi)                    # 圆周率 π

import time
# time.sleep(2)                   # 让程序睡2秒（以后做定时任务常用）
```

| 标准库 | 能干嘛 | 生活例子 |
|--------|--------|----------|
| `random` | 随机数、随机抽签 | 抽奖、掷骰子、生成验证码 |
| `datetime` | 日期和时间 | 计算"今天距双十一还有几天" |
| `math` | 数学函数 | 算面积、开方、三角函数 |
| `os` | 操作文件和文件夹 | 批量重命名文件 |
| `time` | 时间、暂停 | 定时提醒、程序休眠 |

### 二、import 的几种姿势

```python
import random                    # 1. 整个工具箱请进来，用时 random.xxx
print(random.randint(1, 10))

from random import randint       # 2. 只请其中一件工具，直接用它
print(randint(1, 10))

from random import randint as rnd # 3. 请来还起个外号（别名）
print(rnd(1, 10))

import random as r               # 给整个模块起外号
print(r.randint(1, 10))
```

> 💡 日常最常用第 1 种（`import 模块名`，清楚明白）和第 2 种（`from 模块 import 工具`，省事）。
> 别贪多，先掌握这两种。

### 三、第三方库：全世界的免费工具箱

标准库再强也有限。真正让 Python 封神的，是**第三方库**——全世界程序员写好、免费开放出来的海量工具箱。

## 📅 Day 19 · 综合实战：批量重命名小工具

> 🎯 **今日目标**：综合运用函数、循环、文件、模块，做出一个**真正能用在生活里**的小工具。
> 做完这个，你就能拍着胸脯说"我会用 Python 解决实际问题了"。

### 一、从一个真实痛点出发

假设你有个文件夹，堆了一堆旅行照片，文件名乱七八糟：

```
IMG_2310.JPG
IMG_2311.JPG
微信图片_20231001.jpg
截图.png
...
```

你想把它们统一改成 `旅行照片_001.jpg`、`旅行照片_002.jpg`…… 一个个手动改？几百张能改到你怀疑人生。

**这种"重复、量大、规则明确"的活，正是 Python 的主场。** 还记得 Day 1 让你列下的"枯燥重复的事"吗？今天就来干掉第一个。

### 二、认识 os 库：操作文件和文件夹的专家

这个工具要靠 `os`（操作系统）库，它能列出文件夹内容、重命名文件：

```python
import os

# 1. 列出某个文件夹里的所有文件名
files = os.listdir("我的照片")      # 得到一个文件名列表
print(files)

# 2. 重命名文件：把 old 改成 new
# os.rename("我的照片/IMG_2310.JPG", "我的照片/旅行照片_001.jpg")
```

两个核心本领：
- `os.listdir(文件夹)`：看看文件夹里都有哪些文件（返回列表）。
- `os.rename(旧路径, 新路径)`：给文件改名。

> ⚠️ **重命名是"写操作"，会真实改动你的文件，不可乱来！**
> **务必先拿一个"测试文件夹"练手，别直接拿珍贵的照片试。** 养成"动真文件前先备份、先测试"的习惯，这是程序员的基本素养。

### 三、思路设计（先想后写）

用大白话把任务拆开：

1. 指定要处理的文件夹。
2. 只挑出"图片文件"（按后缀 .jpg/.png 判断，用 Day 5 学的 `endswith`）。
3. 给挑出的文件按顺序编号：001、002、003……
4. 用 `os.rename` 一个个改名。
5. 命名格式：`旅行照片_001.jpg`。

### 四、完整代码（带注释）

```python
import os

def 批量重命名(文件夹, 新名字, 扩展名列表):
    """把文件夹里指定扩展名的文件，统一改名成 新名字_001、002..."""
    # 1. 取出所有文件，挑出符合扩展名的
    所有文件 = os.listdir(文件夹)
    图片们 = [f for f in 所有文件 if f.lower().endswith(tuple(扩展名列表))]
    图片们.sort()                     # 排个序，让编号稳定不乱

    # 2. 准备编号，从1开始
    编号 = 1

    # 3. 挨个改名
    for 文件名 in 图片们:
        后缀 = os.path.splitext(文件名)[1]        # 取出 .jpg 这样的后缀
        新文件名 = "{}_{:03d}{}".format(新名字, 编号, 后缀)  # 拼成 旅行照片_001.jpg
        旧路径 = os.path.join(文件夹, 文件名)
        新路径 = os.path.join(文件夹, 新文件名)

        os.rename(旧路径, 新路径)
        print("已改名：", 文件名, "→", 新文件名)
        编号 = 编号 + 1

    print("全部搞定，共处理", 编号 - 1, "个文件")


# ---- 主程序 ----
文件夹 = "我的照片"                        # ← 改成你要处理的文件夹名
批量重命名(文件夹, "旅行照片", [".jpg", ".png", ".jpeg"])
```

### 五、几个新知识点，拎出来说说

**① `"{}_{:03d}{}".format(...)`：格式化字符串**
这是把变量"填"进文字模板的方法：
- `{}` 是个空位，按顺序被 `format` 里的值填上。
- `{:03d}` 表示"填一个至少3位的数字，不足补0"——所以 `1` 会变成 `001`，`42` 变 `042`。这样文件名排序才整齐（不然 `10` 会排到 `2` 前面）。

**② `os.path.splitext(文件名)`**
把文件名拆成"主名"和"后缀"两部分：`("IMG_2310", ".JPG")`。我们取 `[1]` 就是后缀，改名时保留原格式。

**③ `os.path.join(文件夹, 文件名)**
智能拼接路径，自动处理斜杠。比手写 `"我的照片/" + 文件名` 更稳（Windows 和 Mac 斜杠方向不同）。

**④ 列表推导式 `[f for f in ... if ...]`
一行搞定"筛选"：把满足条件的挑出来组成新列表。是 Python 很地道的写法，现在眼熟即可，用熟了会爱上它。

> 💡 这些新知识点**不用一次全掌握**。你能照着把程序跑起来、改改参数用起来，就已经达到今天的目标。
> 看不懂某一行，做个记号，以后回头看会豁然开朗。

### 六、安全第一：先"空跑"再"真改"

教你一个专业习惯——**先演练，后动手**。给改名那行加个"开关"：

```python
import os

def 批量重命名(文件夹, 新名字, 扩展名列表, 真的改=False):
    所有文件 = os.listdir(文件夹)
    图片们 = [f for f in 所有文件 if f.lower().endswith(tuple(扩展名列表))]
    图片们.sort()
    编号 = 1
    for 文件名 in 图片们:
        后缀 = os.path.splitext(文件名)[1]
        新文件名 = "{}_{:03d}{}".format(新名字, 编号, 后缀)
        旧路径 = os.path.join(文件夹, 文件名)
        新路径 = os.path.join(文件夹, 新文件名)
        if 真的改:
            os.rename(旧路径, 新路径)     # 只有开了开关才真改
            print("已改名：", 文件名, "→", 新文件名)
        else:
            print("预览：", 文件名, "→", 新文件名)   # 只看不改
        编号 = 编号 + 1

# 先预览，确认没问题再加 真的改=True 真刀真枪
批量重命名("我的照片", "旅行照片", [".jpg", ".png"], 真的改=False)
```

> 💡 **这就是专业开发里"dry run"（空跑）思想**：危险操作先彩排，核对无误再执行。
> 这个习惯能救你很多次命，比代码本身更值得学。

## 📅 Day 20 · 面向对象极简版：万物皆可"对象"

> 🎯 **今日目标**：用最通俗的方式理解"面向对象编程（OOP）"这个听起来高深的概念。
> 今天只建立直觉，不追求完全掌握——知道它存在、大概怎么用，就赢了。

### 一、别被名词吓到

"面向对象编程"，英文 Object-Oriented Programming，简称 OOP。这词听着唬人，但思想其实非常符合人的直觉。

> **面向对象，就是"按'东西'来组织代码"，而不是按"步骤"来组织。**

打个比方。你要描述"一只猫"：
- **它的属性**（长什么样/什么状态）：名字叫"咪咪"、3岁、橘色。
- **它的行为**（能做什么）：会喵喵叫、会吃饭、会睡觉。

面向对象就是让你在代码里造一个"猫"的模板，把属性和行为打包在一起：

```python
class 猫:
    def __init__(self, 名字, 年龄):   # __init__ 是"出生时要做的事"
        self.名字 = 名字              # self 表示"这只猫自己"
        self.年龄 = 年龄

    def 喵喵叫(self):
        print(self.名字, "在喵喵叫")

# 用"猫"的模板，造一只具体的猫
咪咪 = 猫("咪咪", 3)

print(咪咪.名字)      # 咪咪
咪咪.喵喵叫()         # 咪咪 在喵喵叫
```

### 二、两个核心概念：类 和 对象

| 概念 | 英文 | 大白话 | 类比 |
|------|------|--------|------|
| **类** | class | 一个"模板/图纸" | 月饼模具 |
| **对象** | object | 按模板造出来的"具体东西" | 用模具压出来的一个月饼 |

```python
class 猫:        # ← 类：图纸/模具
    ...

咪咪 = 猫(...)    # ← 对象：按图纸造出的具体一只猫
小红 = 猫(...)    # ← 再造一只，各是各的，互不干扰
```

> 💡 一个类可以造出**很多个**对象，就像一个月饼模具能压无数个月饼。
> 每个对象有自己的属性（咪咪3岁、小白1岁），但都遵循同一套模板。

### 三、self 是什么？——"这只猫自己"

代码里的 `self`，理解成"**这只对象它自己**"就行：

```python
class 猫:
    def __init__(self, 名字):
        self.名字 = 名字      # 把传进来的"名字"，存到"这只猫自己"身上

    def 自我介绍(self):
        print("我叫", self.名字)   # 喊"我自己的名字"
```

`self.名字` 意思是"这只对象自己的名字"。这样，咪咪有咪咪的名字，小白有小白的名字，不会串。
**写对象的方法时，第一个参数固定写 `self`**，表示"这是这个对象自己的方法"。（记住这个规矩即可，原理以后自然懂。）

### 四、我们其实早就见过"对象"了

好消息：你前面 19 天，一直在用对象，只是不知道！

```python
name = "hello"
name.upper()          # 字符串对象，调用它的 upper 方法

nums = [1, 2, 3]
nums.append(4)        # 列表对象，调用它的 append 方法
```

看出来了吗？**字符串是一个对象，列表也是一个对象**，`.upper()` `append()` 这些"方法"，就是"对象的行为"。
所以面向对象不是什么新东西，只是把"数据 + 操作数据的方法"打包成一个整体的思维方式。你早就身在对象之中了。

### 五、为什么要用面向对象？（值不值得学）

| 场景 | 适合用吗 |
|------|----------|
| 数据 + 行为紧密相关（如"学生"有属性也有"考试"行为） | ✅ 很适合 |
| 程序变大、要复用、要协作 | ✅ OOP 是业界主流组织方式 |
| 只是写个小脚本、算个数 | ⚠️ 有点大材小用，函数就够了 |

> 💡 **新手的正确姿势**：了解概念、看懂别人的类、会简单用，**但不迷信**。
> 不要一上手就到处造类。大多数时候，先把函数和数据结构用熟，比硬上 OOP 更实际。
> 等你写稍大的程序、自然会感受到"用类组织更清爽"，那时再深入，水到渠成。

### 六、用"对象"的思路改造记账本

感受一下用类组织的清爽：

```python
class 账本:
    def __init__(self):
        self.记录 = []              # 这本账自己有一个"记录列表"

    def 记一笔(self, 项目, 金额):
        self.记录.append({"项目": 项目, "金额": 金额})
        print("记好了")

    def 看总账(self):
        总 = sum(r["金额"] for r in self.记录)
        print("一共花了", 总, "元")

# 用起来
我的账本 = 账本()
我的账本.记一笔("午饭", 25)
我的账本.记一笔("地铁", 4)
我的账本.看总账()      # 一共花了 29 元
```

对比一下：数据（记录列表）和行为（记账、看账）被打包进"账本"这个类里，主程序变得极简。
这就是面向对象带来的**条理**。

2. **理解 self**：在 `报姓名` 里用 `self.姓名`，确认两个学生报的是各自的名字，不会串。
3. **属性会变**：给某个学生的 `年龄` 属性赋个新值，再打印，体会"对象有自己的状态"。

5. **观察对象**（不动手）：`"hello".upper()` 里，`"hello"` 是对象，`upper` 是它的方法——说出你还在哪些地方见过"对象调方法"。

### 📌 今日小结

- **面向对象 = 按"东西"组织代码**，把属性（状态）和行为（方法）打包在一起。
- **类（class）是模板，对象是按模板造出的具体东西**；一个类造多个对象。
- `self` = "这个对象自己"；写方法第一个参数固定是 `self`。
- 你早就天天在用对象：字符串、列表都是对象，`.upper()` `.append()` 就是方法。
- 新手建议：了解即可，先玩熟函数，别过度设计。

| 招式 | 关键写法 | 干嘛用 |

| 打印 | `print(x)` | 显示内容 |
| 变量 | `name = "小明"` | 贴标签存数据 |
| 输入 | `input("提示")` | 等用户打字 |
| 类型转换 | `int() str() float()` | 文字↔数字 |
| 判断 | `if / elif / else` | 分情况办事 |
| 比较逻辑 | `== != > <` / `and or not` | 写判断条件 |
| for 循环 | `for x in 列表:` / `range(n)` | 挨个处理 / 重复N次 |
| while 循环 | `while 条件:` | 条件不到一直转 |
| break/continue | `break` / `continue` | 停止循环 / 跳过这次 |
| 列表 | `[ ]` + `append/remove/sort` | 管一堆同类数据 |
| 字典 | `{键:值}` + `get/items()` | 管成对信息 |
| 函数 | `def f(参数): ... return` | 打包复用代码 |
| 异常 | `try / except` | 接住报错不崩溃 |
| 文件 | `with open(名,"r"/"w"/"a") as f:` | 读写保存数据 |
| 模块 | `import 模块` / `pip install 库` | 借力现成功能 |
| 类与对象 | `class X:` + `self` | 按"东西"组织代码 |

> 💡 不用全背下来。**编程不是背诵，是"知道有这招 + 用时查得到"。** 留着这张表当"招式清单"即可。

### 三、三个必须长期坚持的习惯（比知识更重要）

如果说 21 天你只该带走三样东西，是这三个：

1. **动手 > 眼看。** 看懂十遍，不如敲错一遍。敲错、看报错、修好——这个循环才是真正的学习。
2. **先拆解，再动手。** 面对任何任务，先在纸上/心里拆成小步骤。这比任何语法都值钱。
3. **先跑起来，再完善。** 别追求一次写完美。写个能跑的最简版，再一点点加。完成比完美重要。

### 四、选定你的进阶方向（三选一，或都不选先巩固）

21 天是"打地基"，接下来该"盖楼"了。根据你的兴趣选一个方向深入（选择困难就先巩固 1 个月）：

#### 🧮 路线 A：数据分析（适合：常和 Excel/数据打交道的人）
- **学什么**：`pandas`（处理表格数据的神器）、`numpy`（数值计算）、`matplotlib`（画图）。
- **能干嘛**：几万行 Excel 几秒分析完、自动出图表报表、从数据里挖规律。
- **第一课建议**：拿一个你工作/生活里的 Excel，用 pandas 读进来、算个汇总、画个图。

#### 🤖 路线 B：办公自动化 / 爬虫（适合：想提效、想偷懒的人）
- **学什么**：`openpyxl`（操作 Excel）、`os/shutil`（批量文件）、`requests`（抓网页）、`selenium/playwright`（模拟人操作浏览器）。
- **能干嘛**：批量改名/整理文件、自动填表、定时抓取信息、自动发邮件。
- **第一课建议**：把你 Day 19 的工具扩展，做成"一键整理整个下载文件夹"。

#### 🌐 路线 C：做网站 / 应用（适合：想做出别人能用的东西的人）
- **学什么**：`Flask` 或 `Django`（做网站后端）、一点 HTML/CSS。
- **能干嘛**：做个人博客、投票网站、内部小工具、给小程序做后台。
- **第一课建议**：用 Flask 写一个"能显示 Hello 的网页"，再逐步加功能。

> 💡 **不确定选哪个？** 做个"迷你实验"：每个方向花 2～3 天，各找一篇入门教程跟着做个小 demo，看**哪个过程让你兴奋**，就选哪个。兴趣是最好的续航。

### 五、接下来怎么学，才不掉坑

| 阶段 | 时长建议 | 做什么 |
|------|----------|--------|
| 巩固期 | 2～4 周 | 把 21 天的代码**自己重写一遍**，不看书；把猜数字、记账本、重命名工具**加点新功能** |
| 方向期 | 1～3 个月 | 选定 A/B/C，跟一个系统教程，边学边做**自己的小项目** |
| 项目期 | 持续 | 做一个"你真需要"的东西（解决你真问题的最好）——这是水平飞跃的关键 |

> 💡 **最高效的学习法：做一个你真正需要的东西。** 想省时间→做自动化；想省钱→做比价工具；想分享→做小网站。
> 有真实需求拉着你走，比任何教程都推得快。

### 六、给小白的最后几句心里话

- **你会无数次想放弃，这正常。** 每个程序员都经历过"我怎么这么笨"的时刻。那不是真相，那只是你在翻越"新手坡"。熬过去，就是坦途。
- **慢，真的没关系。** 别人三天学完的，你花两周，最后掌握得可能更牢。编程是长跑，不是冲刺。
- **你不需要很聪明，你需要持续。** 每天 1 小时，一年后你会感谢今天开始的自己。

> **大魔王博士 敬上。**
> 山高水长，咱们进阶教程里再见。届时，希望你已经成为那个"能想出方案、能动手实现"的人。

## 📎 附录一：常见报错速查表

| 报错关键词 | 含义 | 常见原因 | 怎么办 |
|-----------|------|----------|--------|
| `NameError` | 名字没定义 | 变量拼错 / 没创建 | 检查拼写，确认创建过 |
| `SyntaxError` | 语法错误 | 漏冒号/引号/括号，中英标点混用 | 看它指的 line，查标点 |
| `IndentationError` | 缩进错误 | 该缩进没缩 / 混乱 | 统一 4 空格 |
| `TypeError` | 类型错误 | 文字和数字直接相加等 | 用 `int()/str()` 转换 |
| `IndexError` | 越界 | 列表编号超范围 | 确认长度，注意从0开始 |
| `KeyError` | 键不存在 | 字典没这个键 | 用 `.get()` |
| `ValueError` | 值不对 | `int("abc")` 这种 | 校验输入 / try-except |
| `ZeroDivisionError` | 除以0 | 除数是0 | 判断除数不为0 |
| `ModuleNotFoundError` | 找不到模块 | 库没装 / import 名错 | `pip install 库` |
